# HarborCity 游戏设计数据

- `Economy/DefaultEconomy.asset`：在 Unity Inspector 编辑强类型经济作者数据。正常新城使用资源，不需要在几十个代码文件中改进口/运输价格。
- `Localization/zh-CN.json` 和 `en.json`：新功能按稳定 Key 添加文字，两种语言保持 Key 一致。当前主界面默认中文；旧文字逐步迁移，尚未全部集中。
- 活城市读取不可变 `CityGameDesign`，保存包含该城市的实际设计快照和版本。编辑资源只影响新城，载入旧城按存档快照继续，不偷偷套用新价格。

配置不是资金、库存或报表：这些分别是运行事实与派生查询。无需热更新平台，也不把所有领域塞入一个万能配置类。

仍待迁移：已有建筑价格/容量、未恢复市政设施参数、迁入资金、完整生产配方和旧 UI 文案。当前优先随正在恢复的功能逐步整理；实体安全与几何算法的内部限制不要求全部可调。

R3-C2：同一强类型资源按 Economy、Employment、Retail、Production 分组；工资/班次、零售价格/携货/时间/资本、加工资本/成本/劳动参数已集中。逻辑领域只读对应规则，不依赖 Unity 资源。设计schema/content=2。

R3-C3：Finance 分组保存评估税基、初始税率/预算、道路/管线/三种设施维护和三份贷款报价，设计版本3。运行税率/预算属于城市事实，报价与合同金额/期限随保存冻结。建设价格、供给基础容量与其他未恢复设施仍待迁移；旧参考入口的硬编码不作为新城市规则源。
