# 湾岸 / Harbor City

Unity 6000.6.3f1 + URP 城市建造原型。以《都市：天际线》的道路、分区、城市服务与经营循环为方向；地图、界面与建筑均由本项目代码生成。

## 运行

打开 `Assets/Scenes/SampleScene.unity`，点击 Unity Play。启动脚本自动生成一座示例城市，无需挂载组件。首次运行可能需要等待 URP shader 编译。建议将 Game 窗口最大化，以便阅读界面。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动视角 | 按住鼠标中键（滚轮）拖动地图，或 WASD / 方向键 |
| 缩放 | 鼠标放在地图上滚动滚轮；向上放大、向下缩小，以指针位置为中心，每格视野尺寸变化约 15% |
| 旋转 | 按住鼠标右键左右拖动，或 Q / E；拖动后保留当前建造工具 |
| 俯仰 | 按住鼠标右键上下拖动；向上拖放低视角，向下拖抬高俯瞰，范围 20°–80° |
| 建造 / 连续铺设 | 左键 / 拖拽 |
| 工具 | 1 道路、2 住宅、3 商业、4 工业、5 电站、6 水塔、7 公园、8 拆除 |
| 取消工具 | 地图内右键单击（松开时取消）/ Esc |
| 暂停与继续 | 空格 / 界面按钮 |
| 加速、保存、读取 | 界面按钮 |

道路必须连通地图西侧入口。分区和服务设施必须与连通的道路四向相邻。电站、水塔各提供 160 单位容量，每级建筑消耗 1 单位容量，建筑最高 3 级。供给充足且人口与就业平衡时，分区自动发展。每个游戏日为正常速度下 2.5 秒；城市收取税收并支付维护费。公园改善幸福度，工业和失业降低幸福度。

保存位置：`Application.persistentDataPath/harbor-city.json`。保存保留前一版本 `.bak`；读取会替换当前城市。无存档或格式错误时保留当前进度。退出 Play 不会自动保存。

## 代码与检查

- `Assets/CityModel.cs`：不依赖 Unity 的道路连通、建造、城市增长、经济和存档数据规则。
- `Assets/HarborCityGame.cs`：运行时场景生成、镜头、输入、中文 HUD 和文件存档。
- `Tools/CityModelChecks.cs`：14 项模拟回归检查。
- `Tools/Verify.ps1`：使用 Unity 自带 Mono 编译并执行检查，输出写入 `Temp`。

在项目目录执行 `powershell -ExecutionPolicy Bypass -File Tools/Verify.ps1`。如 Unity 安装位置不同，传入 `-UnityData '安装目录/Editor/Data'`。

## 当前范围

这是核心玩法原型。道路为网格铺设；车辆仅为装饰动画，没有出行需求、路线规划、车道或拥堵。供水供电采用全城容量模型，没有管线与电网。尚未实现坡地、桥隧、公共交通、教育医疗消防、产业物流、地块解锁、破产流程或完整资产系统。幸福度目前为反馈指标，不影响迁入或税率。道路断开时建筑保留，但不计入有效人口、岗位与税收。

后续适合优先扩展道路图与 A* 寻路，再加入通勤、货运和交通拥堵，使城市布局直接影响运行效率。
