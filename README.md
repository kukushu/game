# 湾岸 / Harbor City

开发目标已调整为先复现《都市：天际线》一代的建设与经营体验，再加入差异化设计。当前复刻范围与分阶段验收见 [开发路线](Docs/ProductRoadmap.md)、[基准与差距](Docs/CS1ReferenceAndGaps.md)、[道路与分区方案](Docs/RoadsAndZoningPlan.md) 和 [实施进度](Docs/CS1ImplementationProgress.md)。已开始持续实施；近似规则和未验收内容单独记录。

Unity 6000.6.3f1 + URP 城市建造原型。当前存档格式 24，包含沿路规划、施工项目、规则模式、独立水电管网、垃圾服务、实际购物、个人健康、诊所患者、救护车/步行就医、个人教育、年龄推进/成年/退休、小学/高中/大学独立课程、学校学位/步行上学、实际火灾/消防车/烧毁状态、建筑犯罪积压/警车、建筑升级进度、市政预算、建筑内死亡与墓地/真实灵车，以及城市贷款合同。建筑继续使用独立实体与稳定 ID，居民使用独立递增编号，死亡保留历史身份并退出活人统计。格式 23 自动补充无债务的贷款状态，保留城市；更早开发存档不兼容。

## 运行与操作

打开 `Assets/Scenes/SampleScene.unity`，点击 Play。新城市资金 65,000，无预置道路、建筑或居民。先从西侧入口修路，沿路划住宅、商业和工业用途。放置电站、水塔与水岸排水口，再用输电线和水管接通街区。7 市政面板建设填埋场，垃圾车实际清运，0 选择填埋场可查看库存并清空转运。符合当前条件的土地进入施工并生长建筑，日结时家庭迁入、个人寻找岗位。建设范围为 168×168 世界单位，尺度与供给模型仍待对齐。

## 居民、住房与经营

正常新城启用分区城市规则：普通建筑由私人开发，不扣城市建设费、不注入政府工厂资本；住宅不产生政府维护费，家庭租金不进入财政。居民与岗位仍为真实实体，保留实际通勤、劳动、货运和库存。税收从真实人口与就业活动按暂定税基汇总，点击城市概览的税收按钮调整分用途税率。具体需求、税基、生长时间与初始数值尚为近似，不宣称原作内部公式已复现。当前先提供低密度住宅；高密度与标准里程碑解锁尚待实现。垃圾、供给不足与废弃流程为初步实现，近似参数见实施进度，不作为原作完整规则。

以下为保留在开发回归模式（`development.enabled=false`）中的旧经济行为，正常新城停用冲突规则，不与分区税收叠加：

- 公寓容纳八户，别墅一户。新房为空，家庭按预算、技能、空间、私密性、通勤、储蓄和环境偏好自主迁入；租金进入城市财政，空房也有维护成本。
- 成年成员各自占用具体岗位，每人独立通勤。正常速度 120 秒一天，8:00–9:00 错峰八小时班次；真实到岗后才计出勤。拥堵迟到会减少可工作的时间和工资。
- 工厂有自己的现金、原料、加工进度和成品库存。采购在货车实际发车时付款，到货才入原料库；实际工人劳动完成商品；实际交付才收到销售收入。工资和加工成本从工厂现金扣除，现金耗尽会阻断采购、付薪和加工，并使员工真实返家、重新求职。新厂经营资本来自建设预算，没有自动补款。
- 商业库存属于商业实体；商业采购和商业工资仍使用简化外部经营资金，尚未建立独立商业利润账本。详见 [工业模拟](Docs/IndustrySimulation.md) 和 [居民岗位关系](Docs/CitizenJobs.md)。
- 建筑只有一种用途。住宅、商业、工业、电站、水塔、公园均有对应子类；道路、居民、交通与经济继续由独立系统推进。没有自动等级人口、税收、住宅升级或代表性住宅客运。
- 断路保留实体和居民任务，无实际到岗就无工资；居民等待道路恢复。拆除雇主释放岗位，工人尝试沿现有道路返家；拆除住宅使住户离城待评估，取消其行程。建筑 ID 不回收。

## 观察与日志

按 0 / Esc 后点击住宅、工厂或商业查看详情；F3 打开城市 Dashboard，首先展示需要关注的 Findings，再区分 Live、Today 和 History。可点击工厂、家庭、居民和异常进入详情，查看真实瓶颈证据、住房候选和运输，再定位地图目标。

运行时默认只保留结构化内存分析、最近 750 条关键事件和 180 天历史，不持续生成 events/readable 日志或 Analysis Markdown。F3 可手动导出分析 JSON；只有 Debug 页主动开启完整 Debug Trace 才写原始日志到 `Application.persistentDataPath/SimulationLogs`。分析和 Trace 都不改变模拟规则或正常存档格式。详见 [观察与 Trace 说明](Docs/SimulationLogging.md)。

## 自由道路第一版

- 选择道路后可切换“直线 / 弯道”。直线点击起点、终点；弯道点击起点、终点后，移动鼠标调整弧度，第三次点击确认。确认后可继续延伸。右键单击 / Esc 先取消当前施工，再按一次退出工具；拖动右键仍旋转视角。
- 弯道使用二次贝塞尔形状并按弧长采样到真实路网；预览、路面、车辆寻路、建筑避让均使用这条曲线路径。费用按实际铺设长度计算，整条弯道作为一笔施工撤销。过急弯道拒绝施工，最小曲率半径为道路宽度的两倍（当前 5.4 米，原型参数）。
- 端点优先吸附附近道路节点，其次吸附路段中间。同一平面相交会切分旧路并建立路口，正在行驶的车辆同步转换路线进度。当前提供一种 2.7 米宽的双向两车道占位道路，尺度后续需要统一调整。
- 预览显示长度、施工费用和最大纵坡。成本每 3 米 ¥100（总价向上取整），无效施工不扣费。纵坡上限 35%，横向高差上限 0.95 米；这些是原型玩法参数，不是现实道路设计标准。禁止水面、侵占建筑或分区、过短路段、过近路口、尖角和重叠道路。
- 点“撤销上一笔道路”退还该笔费用，只撤销新建路段，不倒退城市时间、车辆或建筑状态。路口处留下的细分节点继续使用。读取、拆路或脚本重载会清空施工撤销记录；不提供拆除撤销。
- 拆除工具点击路面会选择一段直路或同笔弯道，在路口处停止，费用 ¥40；西侧入口连接段保留。
- 尚无道路拓宽、单行道、桥隧、挖填方和完整分区生长系统。建筑通过最近路段上的明确节点接路，尚未绘制独立车道出入口。路面横坡随地表，复杂路口仍使用简化接头和互斥让行。


## 公共设施与开发模式的沿路建筑放置

正常工具只为公园和服务设施提供单栋放置；住宅、商业、工业改用分区。旧 `PlaceBuilding()` 接口仍用于设施及隔离的开发检查。临时预览投影到最近路段，最大吸附距离为道路中心线 10 个世界单位；曲线暂使用最近短路段方向。

建筑中心距离道路中心线为道路半宽 + 建筑半深度 + 0.25 退距；局部 `-Z` 正面朝路，入口位于这面边界的中央（距中心线 1.6），继续使用 `AccessBuilding()` 连接道路。公寓 / 别墅保留现有尺寸。预览只绘制当前一个贴地地块，绿色表示通过 `CanBuild()`，红色表示超界、水面、陡坡或重叠等拒绝原因，浅色边线标示正面。点击时 `PlaceBuilding()` 再校验并检查资金，按住鼠标不连续盖楼。


不预生成整条道路两侧的槽位，`RoadsideLots()` 已删除。路口或曲线内侧的空隙是否可用，仍由真实轮廓和地形决定。

## 验证与范围

在项目目录执行 `./Tools/Verify.ps1`，使用 Unity 自带 Mono 编译、运行当前实体模型回归，包含稀疏 ID、建造碰撞、弯道、真实通勤、全年家庭资金守恒、工厂现金流、拆除、存档、日志及分析。Unity 菜单 `Harbor → Validate entity architecture and native saves` 使用真正的 `JsonUtility` 检查六种建筑的往返和确定性续算；Play 模式可继续检查建筑视觉和 Terrain。

当前支持自由道路、沿路分区、延迟施工与基础建筑生长、真实居民与货运以及暂定税收。水电仍为容量模型，需求与财政仍需原作对照。桥隧、公交、市政服务、完整解锁、供给网络与完整道路工具尚待实现。详见实施进度，不能将自动回归通过等同于原作体验。
