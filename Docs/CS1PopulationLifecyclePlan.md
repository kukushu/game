# 一代居民年龄、教育与死亡衔接方案

基于当前实体继续实施，不新增原创家庭经济，也不重写住宅详情。年龄推进、成年就业、退休释放岗位和学校年龄离校已实现基础关联；高中、大学已接入独立课程与实际步行学习。格式 23 已接入建筑内死亡、历史居民/遗体关联、有限墓地和真实灵车，出生、途中死亡、火葬与清空转运仍待实施，教育与生命周期的精确规则仍待核实。本文件区分已实现基础与后续验收，不把完整方案当作已完成。

## 已确认与待核实

[一代官方手册](https://cdn.akamai.steamstatic.com/steam/apps/255710/manuals/CitiesSkylines-UserManual_EN.pdf?t=1426004897) 区分儿童小学、青少年高中、年轻成人/成人大学；健康影响寿命，衰老和疾病会导致死亡，真实死者需要灵车送往墓地或火葬场，未处理的遗体可导致建筑废弃。墓地有容量，可清空转运。

当前代码中的 6–13 岁小学资格、18 岁劳动门槛、课程分钟数均为既有近似。年龄推进频率、年龄单位与显示年龄映射、阶段边界、课程完成速度、毕业/离校规则、退休、出生和死亡概率尚未由可访问的一手资料确认。检索出现二代生活路径资料，未采用；第三方慢速老化 MOD 不是本轮复刻基准。不能直接把“365 游戏日一岁”、单纯达到年龄自动毕业或全城固定减人口写成原作规则。

## 最小实体改造顺序

1. 在 Citizen 保存年龄推进的个人状态与最近评估时刻，统一劳动资格更新；先确认年龄单位，再选择并显式标记近似速率。阶段转换不得从人口缓存决定。成年后才可占用具体 Job，退休释放具体 Job，在岗或途中者保留实际位置并完成返家。
2. 先整理学校资格解除与返家：小学年龄结束时释放实际学位，在校者从学校步行返家，途中者从当前节点改道。返回中的 School 任务不能因为已经超过小学资格而被校验拒绝。毕业记录保留，未完成课程不能因年龄变化获得教育。阶段转换和保存必须是一次完整的关联更新。
3. 高中与大学独立建筑、有限学位、实际步行、到校学习、服务停供、课程与返家已接入基础实现。各阶段学习记录独立，同一居民通过真实上课获得三段学历；受控年龄边界不能证明原作节奏。资格、课程、兼职/复学、选择偏好、岗位教育要求仍须逐项核实；边界测试的手工教育值不作为正常玩法证据。
4. 死亡保留真实 Citizen 的历史 ID 与死亡状态，释放工作/学位，不直接删除家庭或扣宏观人口。住宅、实际位置、遗体、灵车与安置设施建立明确关联；活人统计来自存活居民，遗体不当作普通货物或仍在就业的成员。墓地容量和真实搬运先实现，再接火葬与清空转运。
5. 出生和家庭结构衔接在死亡关联可靠后推进。独立居民 ID 计数器已接入，停止使用 `householdId*10+成员序号`，读档后仍继续递增；大于 10 人的家庭不会与其他家庭碰撞。保留已有家庭共同住房和住房单元关系。死亡状态已实现，整户死亡不再进入迁入候选；出生仍待实施。

## 现有代码必须处理的边界

- `CityEducation.ValidEducation`、`DispatchSchool` 和学校更新已区分入学资格与已经在返家的真实任务；超过小学年龄仍可以完成真实返家。
- `CityResidentTransport` 已有按在岗/岗位状态返家，需要使成年、退休、死亡与医疗任务分别处理，避免删除乘客后留下无主车辆。
- `CityHouseholds` 当前人口和住房人数改为真实存活成员；家庭工资仍汇总已经实际赚取的工资，包括死亡前尚未结算的部分，不把亡者或学生计就业。
- 住宅烧毁、废弃和拆除目前将家庭设为待迁入；死亡接入后需分别安置存活成员与遗体，不能共用“离城”等待逻辑。
- 独立累计居民 ID 已实现；格式 23 校验编号计数器、成员、岗位、死亡历史人物、遗体、墓地与灵车关联，未使用的已分配编号也不会因读档复用。途中死亡和转移流程尚未实现，新格式可靠优先，不要求兼容旧开发存档。

## 当前死亡服务边界

建筑内死亡按个人衰老/严重疾病风险评估，释放具体岗位和学位，保留实际死亡位置。灵车派出、接取、返程和安葬分别改变具体遗体状态。断路、墓地停电、满容量和载有遗体时读档已有专项检查；人口与住房人数排除死者，历史身份不复活。80 岁风险起点、每日风险、48 个墓位、2 辆车、3 天积压、医疗预算共享等全部为待核实近似。

原作手册中的火葬与清空转运尚未完成；有遗体的建筑和有占位的墓地目前不能拆除，不当作原作规则。已有出行任务者暂不发生死亡，避免未实现的道路遗体被瞬移回家。后续先补真实转运与火葬，再补途中死亡、出生和整体节奏对照。

## 可重复验收

发展有小学的住宅街区 → 儿童实际学习 → 年龄阶段改变，释放小学学位并实际返家 → 进入高中/大学实际学习 → 成年者寻找真实岗位 → 退休者释放岗位并返家 → 老年或患病居民死亡 → 实际灵车接送到有限设施。每个转折点分别在家、在校、上班、途中、断路、停供时保存读取。验证总人口、学生、就业、家庭工资和遗体数量由相应实体统计，原作同场景操作与速率对照单独记录。
