# R3-D2：建筑、家庭成员与城市问题观察

## 已接入的实际操作

退出建设工具后直接点击建筑；视图通过显示包围盒命中稳定建筑ID，再按ID查询模拟。选中建筑顶部有独立轮廓。菜单“观察城市 / 建筑问题”打开道路、电力、供水、排污、垃圾积压和废弃状态的列表，点击条目定位并选择该建筑。不是从旧CityTraffic读状态。

住宅按“建筑摘要 → 家庭列表 → 选中家庭 → 成员”显示：实际入住/住房数、人口、就业/劳动力、家庭资金、个人岗位及工作建筑、岗位日工资、实际所在建筑，或真实车辆/任务ID、出发地/目的地、购物/上班/返家及道路中断。每位有工作的成员可定位自己的工作建筑，不选择任意一人冒充全家路线。

实际通勤只统计当前住房与岗位已经观测到的就业成员，显示平均、最长和样本数；没有样本时明确说明。孩子不进入劳动力分母；普通空置没有异常标记。本批没有恢复路线绘制按钮、全人口搜索列表、车辆详情窗口或原住宅高级布局，不冒称完整旧UI已恢复。

工厂/商店显示真实岗位占用、在岗人数、当前在岗人员今日工作分钟、原料/商品、企业资金、关联运输/中断数；处理场显示建筑待收与场内库存。信息来自当前实体/任务/供给缓存，不写另一份工资、位置或库存。警报只覆盖已列出的六类状态，不等同于全产业、消防、医疗或经营诊断。

## 边界与生命周期

CityCoreObservation是冷查询投影，读取CityEntities、CityModel现有业务及World公开任务/位置关联。BuildingInspection / FamilyInspection / ResidentInspection是可丢弃副本，成员集合只读；修改副本不会影响模拟。没有单独计时器、后台系统、模拟状态写入或额外存档字段。

HarborCityObservationPanel只拥有当前绑定、稳定选择ID、展开家庭、滚动/分页、刷新时刻和副本。最多每10模拟步或0.5真实秒刷新一次，也因实体/道路版本变化刷新；暂停时政策变化仍会在真实时间刷新。关闭不查询；读档/换城重绑后清空旧选择、家庭与问题状态，不保留旧城引用。城16/业务8/设计4/核15均不变。

新UI不把Time或Transform反向写回模拟。建筑视图独占选中轮廓与显示包围盒；摄像机定位只改视图焦点，读写建筑详情不影响真实位置。面板阻止区域内建设输入与相机缩放，财政模态保持优先。首次轮廓创建是表现层冷分配，不属于交通或模拟实体。

查询实际复杂度：建筑详情O(H+P+J+T)，问题刷新O(B)，点击显示命中O(B)；全部只在交互/节流观察时发生，不在逐车/逐步循环隐藏全城扫描。问题按20条分页，所有建筑仍能访问，不以截断列表掩盖规模。详情/问题副本及格式化文本会分配，尚未建立大城观察UI的时间/GC预算；不能把只读当作无成本。

- 22415城市检查，新增孩子/四劳动者家庭、实际通勤45/60分钟只取两个有效样本得到52.5平均/60最长、空置中性、工作/任务/车辆关联、断路状态、在途保存后重新查询、DTO隔离与100次查询完整保存不变。
- 与56667df同一真实成长消费城12000步：完整存档SHA完全相同。均值0.015038→0.015128ms，P99 0.0480→0.0533，分配同为3449B/步，30居民/26建筑/峰值34车、消费36件/2160收入一致。差异在小样本波动范围；观察不在模拟步里执行，此对照证明没有修改模拟行为，不表示面板零成本。
- Unity普通构建的原地形城市实际运行：新面板/问题列表打开，从同一真实垃圾车在途存档分别运行1x和3x，窗口表见Results/R3Observation/native-window.csv。12居民/18建筑/实际服务车峰值3；1x/3x约60FPS、实际0.9959/2.9998倍率，帧P99 16.981/17.039ms、整体GC 36536/46780B每帧。新增面板有真实界面分配，不宣称零开销。不是模型FPS，也不是大型城市证明。
- Unity程序验证建筑显示包围盒射线返回正确稳定ID、选中轮廓实际绘制、展开真实家庭、100次建筑+问题查询后完整保存相同。12人/19建筑，平均一对查询约0.0021ms。具体结果见observation.csv；没有宣称人工鼠标点过所有按钮。
- 3218道路内核回归、6000步采样开关保存对照、岗位索引分配与原各领域回归通过。原医疗/消防/行人测试通过仍不表示迁入正常城。

Profiler新增 City.Views.Observation.Refresh，只包围实际刷新，不把缓存命中与GUI绘制计为模拟。正常窗口GC包含原宿主、IMGUI、视图和观察；没有声称GC为0。Unity不支持的线程分配计数仍报告未知。

## 数据与变更影响检查

新增本地化Key，中英文共97项；房屋用途、提示、成员状态均通过资源，领域只返回枚举/标量，不拼中文提示。新展示没有配置平衡参数，也没有改变任何经济或服务规则。

涉及Observability读投影、独立UI、宿主点击/菜单接线、视图选中命中、摄像机定位、本地化和验证工具。模拟调度/生命周期、World运动、财政/垃圾/贸易均没有修改。新增查询仍依赖现有公共业务状态，这是明确的过渡读边界；没有把Session变成新管理器、没有让视图成为事实源，也没有引入通用总线或新接口层。模拟可以不加载这些Unity视图独立运行。

当前多日小城市已能持续迁入、就业通勤、原料进口、生产/批发/购物、税收维护贷款及垃圾收运处理。下一批继续补齐实际城市管理/施工体验与仍缺的市政、信号行人能力，保持原版目标；完整UI、桥隧/复杂道路工具恢复、大规模真实综合城市仍不足，不提高笼统复刻百分比。
