# R3 分区静态几何缓存：真实城市配对

本批仅处理已采样证实的分区重建问题，不改变建筑生长条件、需求、消费、交通或时间步。

CityCoreZoning仍是唯一沿路规划缓存所有者：

- 道路NetworkGeneration、建设边界或SetSurface高度源改变：重建道路旁几何/坡度/路面避让。
- 土地用途revision改变：重新应用保存的世界用途印章。
- 建筑或待建项目revision改变：刷新可用性/占用，项目外形每次刷新只转换一次，不在每个格检查时重建。

几何不再随每栋建筑和每个项目变化重算。建筑/项目仍是原实体唯一事实；以上均是可重建查询数据，不另存。不新增数据格式，也不将任何视图对象用作判断。缓存失效在成功刷新后记账；道路切分、实际建筑占用、刷用途、重绑高度源和从保存重建均测试。

## 正确性与范围

2228城市检查、6000步采样开/关状态对照、现有全领域回归通过。新增暖缓存与保存后全新重建对照，覆盖道路切分、建筑更换占用、用途涂改/清除、项目与多日生长、重新绑定地形。原有购物拆路/恢复、实车货运、真实付薪和在途保存继续通过。

影响检查：只有分区缓存生命周期和验证工具改变；没有扩CityModel、World、居民或经济接口，没有循环依赖，没有第二份可写事实。缓存仍保留一份格对象，建筑/项目变化只改派生占用。

仍有成本：占用刷新最坏O(规划格×建筑)，候选脚印搜索仍全表扫描；大城以后应基于实际Profiling做空间候选索引。这一批没有同时改这些算法。TerrainData高度适配、区域显示冷全量重建、财政/垃圾/信号行人/完整观察工具仍待恢复，不称完整城市完成。
