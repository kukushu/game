# 分层显示：所有权与更新边界

正式事实仍由 CityEntities、World、Network 拥有；显示不调用交通 EnsureIndex，不改变预约、固定步或保存协议。实现从19e0c31开始，数据与性能证据见[本轮报告](../Performance/LayeredPresentation-20261102/Report.md)。

## 变更传播

- World 已有位置提交、冻结、出发、任务继续、完成和清退入口只向可选 CityPresentationJournal 标记 ID；每个观察周期去重，没有消费者不积累。实例换城解绑。
- CityEntities 的建筑增删、替换、可用性入口登记 ID。显示读取整笔操作完成后的最终事实；普通模拟不依赖显示。
- CityVehicleDisplayIndex 为64/256/1024单位显示区域维护车辆及用途计数。静态车道弧长区间映射支持位置到区域查询，通常不需要精确姿态；变道、冻结和边界采用准确位置。路网变动只核对已使用几何和关联演员。初始化、换城、冷读允许全量建立。
- 建筑索引按中心归属唯一叶块，父块计数不重复；每级包围盒覆盖完整建筑，而非只依赖中心所在的名义格子。跨块拾取不会漏掉建筑。

## 表示与资源

- HarborCityDisplaySettings 集中屏幕像素阈值、滞回、预取边缘、个体创建预算和父网格准备预算。
- 车辆近景池化个体，中景共享立方体网格按用途实例绘制，远景区域用途密度标记来自真实计数。远景不逐车采样姿态或更新Transform。姿态缓存仅保留当前候选范围，摄像机不动且事实没变时复用。
- 建筑近景保留现有立方体外观，中景64单位块内按用途合批，远景父块使用真实位置与旋转的屋顶占地网格，保留道路空隙。镜头切换不重建这些网格。
- 个体准备受共享每帧64个/约1ms软预算约束。待准备车辆直接用批量表示，建筑整叶块准备齐才替换批量；主体互斥。选中建筑优先准备，其轮廓注释与稳定身份不依赖主体GO。
- 建筑变化立即更新叶块，失效父块禁用、回退当前子块；父块在单线程软预算内延后准备。单个Mesh构建不可中断，因此软预算不保证严格最大帧时长，需持续测量。
- 道路继续复用原64单位网格及完整几何，只在镜头/网格变化时按实际Mesh Bounds筛选。分区保留全部近景格子；远景每真实块/用途显示计数密度标记，正在分区/建路/编辑时保留完整格子。
- 建筑选择查只读空间层级及准确世界AABB，选框查矩阵与稳定ID；回收个体不会删除实体。暂停仍执行镜头查询。远裁剪范围随地图和镜头扩展。
- 旧 Sync(World)/Sync(buildings) 保留为参考，Player `-harbor-legacy-views`选择；开关仅在表现配置，不保存。

## 验证入口与边界

- Tools/Diagnostics/PresentationIndexChecks.cs：区域准确位置独立对照、故意漏通知负控、完整业务/交通保存字节、冷恢复。
- HarborCityPresentationChecks：真实Unity里的近远切换、静态复用、无GO选择、暂停业务不变、跨块、替换删除、负控与换城。
- Tools/RunCityScenarioWindow.ps1：复用现有窗口采样，新增 LegacyViews、DisplayCamera(near/middle/far/sweep)、DisplayChecks。检查模式扫描属于正确性测试，不作为普通FPS成绩。
- 帧CSV分别记录实际个体绑定、批量/摘要代表实体数量、索引维护耗时和准确姿态采样累计次数；这些不是GPU Draw Call的替代口径。
- 当前仍保留既有公共设施与对外连接表现，不在本轮改变它们的业务或另做显示重构。未通过百万真实城市验收；显示索引处理成本仍与实际移动/变化的实体数量有关，不声称模拟本身变成视野相关。
