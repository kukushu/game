# R3-D1 增量建筑视图边界

HarborCityBuildingViews（Presentation/World）独占建筑GameObject，按模拟稳定建筑ID维护。它只读CityEntities.Buildings的只读集合，不写任何实体、库存、资金或时间。CityEntities仍拥有同一事实列表；只读包装不复制建筑。Unity Update请求CitySimulation推进，然后读取结果同步视图，固定模拟步不依赖对象显示。

旧HarborCityRoadCoreGame的建筑全量Destroy/Create循环已删除；渲染外观归独立适配器，不增加CityModel业务partial。新增/删除才创建/销毁对应对象，已有建筑更新Transform。道路或分区变化不再触发建筑重建；建筑结构修订改变才更新，加载替换世界时也按ID对齐。生成道路/区域网格目前仍为冷全量更新，明确待后续针对证据改进。

同步仍O(B)扫描，每次结构变化执行，复用HashSet/删除列表；不声称已经做到O(变更量)事件调度。没有通用事件总线或双线程快照。外部直接修改旧public字段不是支持的命令，当前模型仍有部分这类过渡风险。

真实Unity原地形窗口：19建筑连续20次同步，已有对象身份全部不变、创建数19→19，平均0.00452ms，循环分配0B；前后完整模拟保存完全相同。继续真实居民、雇主付薪、货运和消费的多日/读档验证通过，2209模型检查继续通过。仅小城样本，不代表万人完整城。窗口1x/3x仍约60FPS，具体CSV见Results/R3Views。

变更影响：表现层新增一个明确对象所有者；生命周期层仅增加只读集合入口；宿主只保留同步调用/判断修订；模拟算法、任务规则和格式没有变化。既有素材仍占位，美术可替换不要求改经济或交通算法。

仍待处理：地形Height来自TerrainData适配，纯模拟虽可注入高度，但完整原地形的独立数据所有权尚未完成；宿主仍有直接低层道路命令、内嵌验证协程和旧文字；财政/垃圾/信号行人/完整管理UI没有因这次视图改动恢复。
