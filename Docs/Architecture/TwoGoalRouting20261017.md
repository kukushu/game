# 双到达方向共享路线搜索：正式单线程实现

## 原因与范围

返家6751步需要2226条新蓝图，其中2021条真实提交成功；两侧完全堵塞仅9条。增加派车预检只能避免约0.4%的新搜索，所以没有实施。旧双向建筑路线按两个出发方向×两个到达方向做四次Dijkstra。本批由同一出发方向一次搜索两个到达方向，再比较另一出发方向；不改变出勤、准入、车辆、安全、路口、工资或经济规则。

Network.RouteToEither是唯一的可重建路线搜索核心；单目标Route委托给它，不在运行时保留旧引擎。优先队列顺序、严格前驱更新、原目标同分优先、原出发侧同分优先与原路线计价不变。两个目标允许相同代价的继续搜索以覆盖零长边界；同车道前向直达保留原快速路径。单行等不满四组合时仍最多原有两次搜索。纯秒数MinimumTravelSeconds独立职责保留，不生成路线；不扩LRU、不新增道路事实或存档字段。
