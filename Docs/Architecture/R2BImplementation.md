## B1：已实施独立位置

VehiclePosition 是每车唯一物理组件：Drivable ID + 从有向共享几何起点量出的车身中心距离。Vehicle.Current/distance 只是只读投影，已删除从Plan/cursor取位置的实现。MoveStep意图从实车物理锚点读取当前几何，只从Plan读取下一段；提交同步导航进度，校验段ID一致，不维持第二份可写位置。

RoutePlan仍保存导航链（含当前锚点供校验）及终点站位，cursor是导航进度，不是位置。变更Plan不会移动实车；不一致在载入/校验/提交时拒绝。允许路径出现重复车道，不靠FindIndex猜进度。派车/换道完成/道路事务/原位恢复均提交独立锚点。

中断是同一位置组件的Frozen模式，保存世界坐标并保留原ID/距离用于恢复和审计；这些原锚点不再被当成活路面位置。旧Vehicle.strandedPosition只读映射，未保留第二个可写XYZ。移除道路后不丢任务/Shipment，不传送；恢复必须把冻结坐标精确投影到新路面，保留任务并验证连续性。活动和冻结模式/状态必须一致。

组件为每车一次创建的受控对象，不在每步new位置。最初大值结构的拷贝回归已实测，改为组件避免热点大结构拷贝；提交仍有O(1)检查成本。没有改跟车、换道、路口预约、经济或固定步。

## B2：连接审查与下一批边界

**B2已实施并达到有限验收。** Lane、LaneConnection、JunctionPort是明确的不可由UI单独修改的派生语义。PhysicalRoad仍唯一保存中心线/方向/车道数；Network根据实际节点连接生成端口和有向连接，采样点不是寻路顶点。车道Geometry保留完整坐标参数用于施工映射，但实际通行区间由端口StartDistance/EndDistance限定，模拟、空间查询和Mesh均按此范围读取；不是又存一份可编辑路面。

真实交叉和变宽衔接端口退到保护区边界，三次曲线连接实际进口/出口，控制点沿端口切线。普通同宽连续几何切分不额外引入路口或大转弯。LaneConnection拥有Incoming/Outgoing引用与同一共享曲线；冲突检测读取该曲线加进出车的保护长度，而非另一条节点中心假路径。转弯成本/实际行驶/渲染长度来自相同范围。

停车线/等待区、预约重建、进入下一段的起始距离、出口空间检查、反向/环路入口的寻路成本同步适配端口。修复了测试发现的旧预约边界导致的错误冲突。环路可达性独立于某个非法零站位，不会把真实上游环路排除。入口落进新路口区域时升级先失效，城市门口绑定器重新投影合法车道；已在被裁剪区域或正在使用会改变的连接几何的车不能挪动，施工拒绝并保留完整城状态。测试改为“占用路口施工拒绝且状态不变→等待车驶离→再成功”，没有删除安全断言。
