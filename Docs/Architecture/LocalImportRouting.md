# 已完成的原料入口选择实验（与窗口优化分开）

此批在用户开始人工观察前已实现并测试，随后暂停；现在独立归档提交，不作为三万人窗口优化的收益。成品就近匹配、商店周转、经济生命周期及日长均未修改。

`CityImportSources`仅拥有单个贸易阶段的可用入口候选和复用排序空间。先检查4个在途名额和出发车道占用；保持工厂轮转顺序，按有向自由流路线耗时择口，同分按稳定端点ID。欧氏距离/最高道路速度只用于安全下界剪枝，不能代替实际道路可达性；失败准入尝试下一合法候选，成功后移除已堵出发点。没有维护工厂×入口路线矩阵。入口数远少于工厂/商店数，本批不将这种入口遍历扩展到所有商店。

`World.FreightTravelSeconds`仅提供交通静态成本报价，复用原4096项DispatchRoutes LRU。报价不创建任务或修改库存/现金/物理占用；道路/入口变更仍由原缓存失效路径处理。真实派车、付款、预约、货物和到达结算继续原事务边界；无新的存档字段或运行事实。
