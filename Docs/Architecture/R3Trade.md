# R3-C1：有价原料运输、真实出口与设计数据

2026-10-15 五小时任务第一批。继续阶段A成果，不重写交通或虚构居民。

## 当前正式入口

空城先修路、划区并建设水电排污。把道路接到可建设地图边界，使用“标记对外道路连接”点击该处道路。双向道路生成独立进城/出城端点；单行只生成允许方向。连接不是假工厂或仓库。初始地图仍不放居民或预建城市。

工厂按有限现金、实际供给、仓储需求和在途预留采购原料。准入成功才一次扣工厂现金、记录 rawCosts 和城外收款；材料由唯一 Shipment 持有，实际到达才能进入工厂 raw。堵车和拆路不会退款后再创造货物；付过款的材料仍在原物理位置的中断车中。实际工人到岗、有原料及供给才加工。城内商店先获得补货机会，工厂超过配置的剩余成品阈值后才出口。

出口发车从工厂扣库存，城外有限账户预付到运输托管；到达后才形成工厂收入。`exportFunded-exportPayments` 必须等于在途出口付款，绝非发车即售出。城外现金由初始资金、原料收款和已托管出口款计算一致。

这一批尚保留原私人企业外部工资/商店经营资金近似。消费与真正商业账户是下一独立批次，不称完整经济闭环已经完成。

## 所有权与生命周期

- CityCoreTrade 拥有采购/出口规则和城外交易账本；只读 CityTradeState 通过内部入口写入，公共可写字段只存在冷存档 DTO。
- CityEntities 索引独立 OutsideConnection，同城市端点计数器分配稳定身份；现有 nextBuildingId 名称仍为历史命名，实际分配建筑及城市交通端点，后续可局部改名，不存在两份可独立修改的ID计数。
- World 只保存交通入口、任务/货物及物理车辆，新增货种为协议值，完全没有进口库存或企业账户。
- 端点方向由真实车道向城市内部的方向决定；道路编辑后的重绑保持进/出语义，不用允许任意逆向行驶绕过路网。
- 原料与出口资金预留按真实活动任务重算，不保存第二份候选/预留真相。
- 城市13 / 核心14 保存只读设计快照、端点、账本、货种与全部原有在途状态。配置 schemaVersion 1；没有保存设计快照的文件拒绝载入。

## 配置与本地化

`Assets/Resources/GameData/Economy/DefaultEconomy.asset` 是强类型 ScriptableObject，普通新城读取它。可在 Unity Inspector 编辑进口价格、批次、补货目标、出口阈值、城外初始资金、门口派车能力和调度间隔。`EconomyDefinition` 为作者数据，CityGameDesign/EconomyRules 是城市的不可变运行快照，后者整体随存档保存。修改资源影响新城，不追溯改变旧城订单。时间参数按固定步向上量化，数值边界是实现约束。

新提示使用 `CityRuleException.Key`，由 UI 查询语言资源；逻辑不拼中文完整提示。zh-CN/en 的新交易按键和错误位于 `Assets/Resources/GameData/Localization`。旧 UI 文本、建筑容量/价格、工资及生产常量仍有迁移清单，不能声称全项目已经数据驱动。

## 事务与变更影响检查

1. 经济/实体/存档：必须新增独立端点、账本、设计快照和恢复，不把事实挂在视图对象上。
2. 道路/交通：只增加货种存取、批量入口验证，以及准入/到达的只读预检查；没有修改运动、跟车、换道、时间步长或碰撞规则。
3. 构造与生长：在注册实体前先验证道路入口，避免正常验证异常发生在第一笔实体写入之后。
4. 表现层：只读状态、发送连接命令、加载作者资源并翻译 Key；不拥有账本。诊断街区由实际生产命令从空城建立，不是正式模拟里的测试开关。
5. 源枚举从旧 CityTraffic 移到独立协议文件；未启用旧引擎。CityModel 仅增加事实根引用和销售价格参数，不增加贸易 partial 业务。
6. 发车按健康单线程边界：准备路线/入口/预约并验证版本→领域检查与资源转移→同版本提交。业务准入不修改路网或物理状态，因此提交的已有前置条件不会被回调改变。到达也先核对活任务/车/货量，再结算并 ACK；不存在跨渲染帧保存半笔交易。不是通用数据库事务或多线程保证。

## 风险与下一批

采购每个配置周期扫描实际任务和工厂、少量边界端点，O(T+F×P)，不是每车全城扫描。局部源站背压与可达性索引保留；企业大量增长后需要实际街区负载归因。未声明10000车完整城市已验证。

原管线覆盖冷查询 O(B×U)、沿路格冷重建和建筑/分区视图全量重建仍有成本。真实地形高度当前还经 CityLandscape/TerrainData 适配器提供；头less可注入纯采样器，但相同原地形的无Unity数据入口尚未提取。这是表现层承担地形生成数据的过渡依赖，不能称模拟/视图已完全独立。原地形上的部分面片仍会被地形遮住，不能为了显示而反向修改车的位置。

下一批：居民实际到店/返家消费、有限商业现金、真实工资与结算，随后财政垃圾。停止扩大孤立交通引擎。之后结合实际性能与交互批次局部收紧宿主命令和增量视图，不做双线程/通用事件总线。
