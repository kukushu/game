# MS-018 家庭按需调度审计与实验

冻结基线以本轮实际检查的 `b91acda1a257e186a762f7c162905a1928734f7d` 为准。正式分支不改。此候选以 `CITY_HOUSEHOLD_SHOPPING_SCHEDULE` 独立构建，默认仍保留原家庭轮询；验收前不标DONE。

## 依赖与保守边界

原Step仅在development开启、NextTick到期、达到ShoppingStartMinute且至少一家店有货营业时遍历家庭；NextTick更新及全部门店/成员/出行规则不变。新索引只产生候选，不直接派车，不另存家庭事实。

|事实/依赖|写入口及处理|
|---|---|
|存款|初始/读取、Population迁入、Payroll工资、Finance税费、BeginVisit付款；显式保存属性保留原名/类型/运算，写入只标记家庭；原完整账目在事务后读取|
|购物日期|居民成功Depart购物时写入，冷读/直接受支持赋值均覆盖；跨日原day比较变化，一次重新分类，不按假定午夜时间自行派车|
|residency/home/成员结构|复用唯一Entities owner，Home/Residence通知；AddFamily/AddResident/Move/Remove记录结构或受影响家庭，保持society.families序而非Members序|
|dead/sick/atWork/tripId/location|已有受控通知标脏，事务完成后分类；全员被这些确定阻塞时可休眠|
|retryAt|复用既有CityWakeQueue，仅登记最早可能时刻；只在原购物周期兑现。保留购物原 `Clock>=retryAt` 的NaN/Infinity/float边界语义|
|age/carriedGoods|仍有原始字段写入，不能依赖完整通知；**不因它们休眠**，其余条件满足的家庭继续原周期轮询，原人选顺序与完整谓词仍执行|
|工作/工资/岗位|岗位本身不是购物谓词；atWork、所在位置和存款的真实变动负责失效，不提前预测下班、收入或资金|
|店营业/库存/供水电/员工|保留原每周期商店索引和Open实时读取；不因店关闭/没库存/不可达而让家庭长期休眠，故无需臆造全城营业通知|
|建筑/道路/失败/恢复|家庭候选不缓存可达性或门店。原周期重读home、店和Network；不跳过原派车/失败retry/恢复规则|
|冷加载|事实先读取、owner重建，派生候选/位图/队列第一次使用时从当前事实建立；无新保存字段/格式或兼容层|

setter与成员回调只去重标脏，不在部分交易中判断资格。候选枚举在每次取下一个家庭之前刷新待处理变化：较后家庭同Tick被唤醒会按原序处理，已走过的较早家庭不重新访问。位图与队列由Consumption单一拥有；不把通知覆盖率当性能收益。

## 实现与判定

Consumption唯一拥有 `CityHouseholdShoppingSchedule`：原序家庭槽位、ready位图、复用CityWakeQueue的最早重查Tick、去重脏家庭。Entities仍拥有唯一事实，通知只标脏，每次取下个家庭前读取已完成交易的状态；较后家庭同轮唤醒，已处理家庭不重做。完整谓词、人选/门店/半径顺序、retry及RequestShopping保留原代码。

标脏摊销O(1)，定时队列O(log H)，按位图原序枚举，变化分类只读相关家庭成员；首次、结构变化、跨日仍可O(H+P)，真实候选的可达性/准入计算不会消失。属性保留原保存名称/类型/默认值和运算次序，格式18不变，无兼容层。

**结果：无可靠整体收益，保留原轮询；MS-018仍IN_PROGRESS，不推荐默认启用或正式集成本候选。** 保留编译开关用于独立复查，不宣称完成全家庭事件调度。
