# MS-018：重复目的地共享搜索界限

2026-11-01，基线 `eb2e336`，当前独立执行分支。不合正式开发分支。车道对缓存仍8192/8MiB，垃圾场树容量、居民和购物规则不变。

## 实现与正确性边界

上一轮的购物峰值仍约1.14秒：大量家庭前往同一商店，但起点不同，车道对缓存不能消除首次搜索。此次不从反向树直接生成车辆路线，以免改变等成本路线、出发侧和准入结果。

`CityCoreConsumption.Step` 仅在原购物循环外开启同步查询批次；循环顺序、候选顺序、库存与资金读取、重试和实际派车不变。一个目的车道在批次内累计16次缓存未命中搜索后，按需复用现有 `DepotGraph` 和反向 `DepotTree`。每个不可变Network最多四棵界限树、每批最多构造四棵；容量满时清理派生界限，不清理已有路线。没有新的可编辑路网或保存字段。

- 反向树的hop提供一条可行路径。按原搜索的正向加法顺序累加，得到可行成本上界；不将该路径交给车辆。
- 反向distance包含当前车道通行时间，扣除后得到余下成本的估计下界。原A*仍使用原空间启发、堆排序、严格小于更新、邻接顺序和父节点恢复。
- 只有确定不能胜过上界的分支才不入队。等成本分支保留，原最优路线与确定性选择须通过精确对照，不使用成本容差代替路线一致。
- 浮点防护覆盖反向与正向加法顺序、扣除自身车道成本的消减误差。令N为全图车道数，u=2^-52，q=8(N+1)u，使用 `8*q/(1-q)*(反向距离+自身成本+前缀成本+上界+1)` 的保守裕量。非负简单路径至多N个车道，裕量覆盖累计加法及界限比较；+1也使极小数成本退回不剪枝。非有限值、不可用hop、同车道环回及过大误差界限均回退原搜索。没有提高交通或经济断言容差。
- 普通移动、预约、时间和建筑入口偏移不改变静态树；精确入口偏移仍在原AccessCost中计算。道路、速度或方向变化生成新Network，旧树不再被新世界查询。旧Network仍可由其合法旧持有者使用。

复杂度：每个热门目的地第一次额外O((V+E)logV)建树，后续每次仍执行原A*，但可排除大量与目的地无关的扩展；每次上界恢复O(路径长度)。不是O(1)寻路，也不保证所有路网获益。四棵树的数组空间O(4V)，已有图共享；不为每栋建筑存整条树路线。
