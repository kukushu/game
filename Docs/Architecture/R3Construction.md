# R3-A：恢复空地建设与分区生长

实际接入正常游戏启动，而非另一个交通演示。默认地图没有预建道路、房屋或居民；原地形生成器与相机供建设工具使用。交通诊断参数仍可启动隔离夹具。

## 数据与运行链

- `CityCoreConstruction` 执行预算检查、RoadEditPlan 原子提交和扣费。失败不扣费，重复提交不会重复扣费。现阶段路费按中心线长度、车道数与现有 40/3 系数近似，并非完整原版道路价格表。
- `CityZoningState.designations` 是保存的土地用途事实；`CityCoreZoning` 的沿路单元是派生规划数据，不是建筑数据库。按路网、建筑及规划版本失效；世界位置印章在非网格整齐的中途拆分后保持土地用途。
- `CityCoreGrowth` 在 CitySimulation 健康步边界推进原有需求及建设规则，经过计划和施工时间产生真实建筑。完成时由 CityEntities 注册建筑及有限岗位，再绑定真实道路入口。没有虚构人口，也没有旧交通网络。
- 建筑拥有基础高程和门口高程；道路共享几何供规划、通行、入口投影与渲染使用。地形采样回调是运行时依赖，载入后由地形宿主重新绑定。
- 新城市存档版本 11 / 交通核心 13，保存地图参数、分区用途、未完工项目、调度时刻以及已接入的业务实体。旧格式明确拒绝，不删除原文件。

目前按 6 秒检查开发需求、12 秒施工，复用原项目占地与需求公式。这是现有近似规则，不声称已核实为《都市：天际线》一代内部算法。住宅私人生成，租金为零；政府不直接盖住宅收租。

## 已验证

Unity 独立窗口以真实原地形启动空城，通过输入系统模拟两次鼠标点击，走正常射线与道路建设工具、扣费链，再通过实际住宅分区刷输入和领域命令覆盖三种分区。验证定时建设、独立建筑/岗位、三维入口、未完成项目保存与逐步一致继续运行。截图和原始日志保留在忽略目录 `Temp/RoadCore/Construction`。

领域测试覆盖余额不足、重复提交、暂停、住宅/商业/工业生长、清除规划取消建设、水下不能生长、非整齐道路拆分后用途保持、新格式恢复、实体与交通引用完整性。道路与城市回归分别运行；旧功能测试通过不等于它们已迁移到新运行链。

## 尚未恢复与风险

居民迁入、自动就业、持续原料进口、居民消费、市政供给、税收维护预算贷款及完整观察界面仍待接入；此版本不能验收为完整可经营城市。已有工厂到岗生产、真实货运与结算在诊断城市中工作，但不代表空城已具备持续生产条件。

目前只有基础低密度分区和地面道路交互。桥隧、曲线、复杂升级工具与完整管理 UI 尚未恢复；内核支持相关几何不代表工具恢复。沿路规划冷重建及显示对象重建仍有成本，尚未验证大型成长城市施工性能。原版土地格尺寸、需求和价格仍是近似。

## 下一批

优先恢复真实人口迁入、住房与自动就业，通过已有 CityCoreResidents 发出通勤和返家任务。生产依赖市政供给不应悄悄绕过；随后接持续进口、商业消费与基础服务，建立多日可持续的真实城市闭环。停止扩大孤立交通内核。
