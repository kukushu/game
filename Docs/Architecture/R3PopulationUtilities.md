# R3-B：基础供给、迁入、自动就业和实际出勤

日期：2026-10-15。R2-B有限验收结束后，此批继续恢复城市功能，没有扩大独立交通引擎。

## 实际接管

正常空城启动已提供电站、供水站、排污口、电线和水/排污共用管建设工具。设施由 CityCoreConstruction 校验地形、占用和真实道路入口后，通过 CityEntities 注册并一次扣款。管线直接提交原 CityUtilityNetwork 的候选网络和扣款，不调用旧城市 Recalculate 或旧道路寻路。

CityCoreUtilities 复用原来的连通分量、覆盖、独立管网容量和负荷分配规则。BuildingAccess 在新城市经 CityEntities 读取唯一 RoadAccess；旧交通图为空，不是供给条件的隐藏后门。供给是派生状态，不存第二份真相；在路网、实体、管线实际改变或就业负荷改变时重建。原居民/岗位负荷改为每次重建单次聚合，避免每栋建筑扫描全城居民和岗位。建筑与管线覆盖仍有 O(B×U) 的冷查询；没有宣称已经适合无限城市。

CityCorePopulation 在健康模拟边界按原每日申请上限迁入家庭，只有真实空住房、道路、电、水和排污均满足才入住。家庭和个人通过 CityEntities 注册；各人按劳动能力、技能和可达岗位分别就业，不按家庭数增加就业。寻找岗位按工作地点分桶，同一次调度每个 home/work 组合估算一次路线，不对每一个相同楼内岗位重复寻路。仍需检查失业者与候选楼宇，复杂度并非常数；查找每六秒运行，不进入车辆热循环。就业截止时间保存于 development.nextEmployment，迁入日界由 society.lastSettledDay 保存。

已有 CityCoreResidents 继续负责真实上班/返家、到达确认和工资日结。修复原迁移链只处理工业员工的遗漏：商业员工也按实际到岗积分工资；私有发展模式按 earnedWages 支付，原现金工厂模式按 factoryWageCredit 支付，生产读取各自规则对应的实际已付劳动。仍保留已明确的私人企业工资外部资金近似，不声称已建立完整企业/居民财政守恒。缺原料、缺供给或仓满仍阻止加工。

## 唯一数据与保存

- 建筑、家庭、个人、岗位及管线是原事实对象；CityEntities 索引不复制。
- 交通仍只使用新 World、VehiclePosition、RoutePlan、TripTask 和 Shipment。
- 供给连通分量、每栋负荷和岗位候选都是派生数据，读档重建。
- 城市格式 12 / 核心 13，新增保存真实 utilities 和就业调度时刻；旧格式拒绝，原文件保留。此保存覆盖已接系统，还不是全套恢复后完整城市格式。

## 正确性证据

2180 项集成检查通过：缺供给不迁入；设施和管线扣款；住宅供电供水排污；两户七名真实居民中四名劳动者、三名符合工业技能的就业者；真实派车、到岗、工作与返家；在途道路非整齐切分不传送；新保存继续完全一致；排污支管拆除使排污容量变零而保留电力。显式有限原料的测试验证私有工厂确实加工，空原料另一个测试保持零产量。

原有道路内核检查、1k/3k/10k实际活动车内核夹具及旧功能回归通过；旧回归不代表这些玩法已恢复。Unity 独立窗口验证原地形空城实际鼠标道路/分区输入，三用途建筑生长、设施管网、迁入找工作、车辆出勤与返家、未完工和在途保存恢复。设施管网通过同一生产领域命令建立；并未声称本轮自动点击了所有新 UI 按钮或测试了用户当前编辑器城市。

## 性能与边界

同源原 R1 配对夹具：3000 居民、750 工厂/商店、200 步，峰值1500活动车；before 1.266936 / after 1.276431 ms/步，P99 10.3769 / 10.4111 ms，均14292 B/步，产量/交付均5250。差约0.75%，未证明加速；主要用于防止破坏已有运行链。该夹具关闭分区市政且原料有限，不能作为新完整城市性能结论。

公共语义摘要只排除版本号和该关闭系统的新 utilities / nextEmployment 字段，其余共有居民、工资、库存、账户、车辆与任务完整比较。独立真实城市的管网、就业调度和继续运行由新格式完整保存逐步比较，不以该摘要掩盖差异。

正常地形窗口另以同一在途城市保存分别测试1×/3×，记录帧时、真实倍率、GC和实际活动峰值，轻量 CSV 在 Results/R3。它仅是小型正在成长且有通勤的城市；不代表1000/3000/10000车综合城市，更不是持续消费进口经济已完成。

## 尚未接入与下一优先级

持续城外原料与出口、居民消费、垃圾处理与服务车、税收维护预算贷款、完整观察管理 UI、交通灯行人及完整曲线桥隧工具仍待接入。迁入暂按原基线在住宅注册，不是城外迁入车辆；住宅废弃/恢复与拆除迁居策略未恢复，不能静默移除在途居民。

下一批优先真实外部物流与消费，接回工厂—商店—居民持续循环，再接垃圾与财政。不能因为单条道路的小城通勤通过就称 R3 完成。之后必须建立复杂、可达、多用途、多日运行的综合城市，再按实际归因扩大规模验证。
