# 真实车辆显示对象生命周期与有限复用

## 已接管的链路

默认HarborCityRoadCoreGame.Update在全部完整固定步后调用HarborCityVehicleViews.Sync。该表现类独占Vehicle ID→Transform和最多4096个闲置显示对象。先用World.FindVehicle的既有稳定索引判断退休，再用退休物体供给同帧出生者。所有发布的World.Vehicles仍逐一显示，4096只限制闲置缓存，绝非活动车/显示上限。车辆、任务、路线、物理站位和城市事实全部仍归模拟；无Unity对象反写。换World/读取/清空/卸载销毁旧显示，借用材质及内置Cube Mesh不当成自有资源销毁。

保留原立方体尺寸、材质、碰撞器、位置和方向采样，避免把关闭PhysX或美术替换混进收益。复用时重新绑定ID/名称、重设新物体应有的初始旋转，继续按真实状态更新。调用者不得把某个Transform当作永久车辆身份，应按当前稳定ID查询。没有修改World/CityModel、经济、交通规则、时钟或存档。

## 成本、边界和后续

每显示帧O(已有显示+当前车辆)，读既有O(1)ID索引，不添加全城任务搜索或新权威索引。仍全量位置/方向同步，仍有激活物体开销，没有相机剔除、批量车辆绘制或线程改造。本批只新增表现所有者并缩小宿主职责，探针追加创建/复用/闲置计数；内部缓存常量不是游戏平衡参数，无新增UI文字。回退通过Git，不在产品保留双套渲染引擎。正式普通Player已重建，没有遗留特殊验证组件。
