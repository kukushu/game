# 分区显示空间合批：2026-10-17

## 问题、范围与所有权

完整三万人城有90733个分区Renderer。临时禁画定位已证明其占据暂停显示瓶颈；正式改动不会隐藏网格、降低细分或减少模拟。保持单线程CitySimulation、原0.05秒、所有真实居民/车辆/货物和规则。

新增HarborCityZoningViews只拥有显示GameObject和Mesh，借用宿主四种材质。按64世界单位空间块和原用途颜色分组；仍展示全部原occupiedBuilding<0单元（含项目占位的原规则），不用available擅自改显示。AppendPlot保留原0.5单位细分、所有顶点、三角形、绕序和高度采样，Plot预览和合批共享同一个表现算法。超过65535顶点的组显式使用32位索引。世界坐标不写回模拟。

宿主继续在道路、用途或建筑修订改变时调用RenderZones；目前仍整批重新生成，尚非增量修改单块。候选几何完整生成后才替换旧显示；失败保留旧对象，Dispose只释放自己拥有的Mesh/GameObject，不销毁借用材质。道路拓扑、共享模拟几何、入口、车辆位置、人口、经济和保存完全未改。

## 风险与下一步

全量分区重建仍会有冷分配/施工尖峰；64单位块使近景剔除比逐格粗，但未改变实际图形，完整近景/相机移动压力还需单独采样。道路和管线仍有大量独立显示对象，不在本批同时重构。共享地形适配仍为既有过渡，不因合批宣布模拟完全摆脱Unity。

后台主要剩余长峰是实际派车和成长扫描，暂停瓶颈解决不代表三万人模拟已通过。下一批继续按明确原因追踪，例如6751的4866次准入和2226条新蓝图；不能直接扩大LRU或复活已拒绝的双向预检。五万/十万仅在已有城市上做有界探测，不以合批推断大城达标。
