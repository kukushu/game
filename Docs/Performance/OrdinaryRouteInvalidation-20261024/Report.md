## 改动及失效边界

`CityRoadCoreDispatchRoutes.cs`在原4096项共享LRU中新增按端点删除，复用删除函数维护链表/容量淘汰。单个入口最多扫描4096项，不新增每路反向索引或权威数据；批量登记复用原合法性检查HashSet，一次扫描。未涉及端点的成功蓝图、标量报价和失败缓存原对象保留，LRU相对顺序不变。查询和车辆独立路线复制机制不变。

`CityRoadCoreWorld.RegisterAccess/RegisterAccesses`仅用上述删除替换全清，入口检查、整批先验证后写入、AccessRevision/EditEpoch不变。即便此前该ID通过路口回退查询或缓存了不可达，也必须删除其相关条目。增加入口没有改变Lane/LaneConnection或其他端点锚点，所以与该端点无关的静态结果仍有效；每次派车仍执行原实时占用、预约、安全及原子提交。

道路新增/拆分/删除/升级/方向变化及已有入口重绑定仍走原Network/事务完整失效，防止保留失效蓝图；加载创建新缓存。没有按新增门口的位置猜测路网依赖，也没有扩大到垃圾路径树/居民个人估计缓存。未改变商店付款资格、候选顺序、目标优先级、固定步或保存格式。
