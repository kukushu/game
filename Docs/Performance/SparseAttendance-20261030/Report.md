## 修改及正确性

原CityProductionSystem每0.05秒遍历所有居民，仅少量到岗者能产生劳动。现在CityEntities维护派生的64成员分块位图，atWork受控setter是唯一写事实，非空块按原Members序遍历。其他健康、家庭、岗位、班次、位置、资金、工资、欠薪、生产及舍入规则完全复用；未缓存第二套资格。同步日志回调存在时保留原遍历，保证回调动态修改后续状态的原行为。

劳动候选从O(N)改为O(A+活动块)，普通状态变化O(1)，块激活/清空O(log块数)。移除释放槽/空块；空洞超2N+1024时按原序重建，限制长期空间，仍有O(N)结构边界重建尚未做大规模尾帧验收。AdvanceIndustry的建筑扫描未改，阶段4并未全部完成。

运行时只改CityResidents.cs、CityEntities.cs、CityProductionSystem.cs、CityCoreSave.cs。atWork改为显式CitySavedFact属性，保存仍按原名称、类型、顺序编码，Version17未变；没有新存档迁移。原有A*、车道对缓存、垃圾车车道树、交通/车辆/经济规则未撤回或修改。两项自动测试：Tools/VerifyAttendanceRoster.ps1、Tools/Diagnostics/CityAttendanceRosterChecks.cs。

冻结a3对照实际通过：222个针对性完整保存检查点、126个混合增长/重划拆分/30k状态检查点，冷热80步相同；直接写状态、重复写、64位槽、1600人交错增删、序号整理、脱离Owner、日志回调变更均覆盖。正式集成后再次运行同样对照与CityCore：23627城市、10000岗位、1522方格、83分区、460474水电检查通过。十组原生固定1200步终态均为2388ff392a6cdc1ced39a4fc527e7870f2a73cd5a6d1ae4b256e2dfe8c67c40d，退出0，各自冷热20步一致。
