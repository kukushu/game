## 带权状态与路径恢复

状态在**进入车道的末端**，该车道此前行驶成本已支付。仅当同一路口的合法出口 Lane ID 集合和对应 `connection.Geometry.Length / connection.Speed` 成本向量逐位完全相同，才合并进入车道。不同进入车道长度/速度由抵达该状态前的实际边处理；不能用出口集合相同推断转向成本相同。

对相同出口 Lane，后继状态和完整车道行驶成本固定。等价类中每个成员均有同样合法、同样成本的后续选择，因此合并保留最优延续；恢复时保存真实进入/出口 Lane，再从 Network 取真实 LaneConnection。不同连接成本必须拆开，没有近似合并。

垃圾场入口恰在车道末端时，该特定车道可零成本终止，同组其他车道不能冒充它。将这些车道固定为单独终点状态，包括另一侧合法入口；由 Waste 活跃场列表和 World 入口版本规范收集，避免首次查询顺序改变分组。部分入口和终端状态均有独立参考测试。

去程以垃圾场两侧合法入口多源入堆，初值为准确剩余车道时间。松弛采用 `(已付时间 + 实际转向时间) + 出口车道时间`。返程对所有合法垃圾场入口反向多源 Dijkstra，以转向时间加准确入口前部分车道时间初始化，保存实际前进方向的下一跳。车道末端终止单独处理。复用 Network 原有优先队列，正式建树中没有 BFS。

建筑查询沿用局部候选的稳定顺序，找到第一个合法入口即恢复路线，不在候选之间再做全图最短比较。返程从车辆实际 lane/distance 接入；同车道前方直接到达保留，目标在身后须合法绕回；保留首次合法目标停靠截断。状态成本查询 O(1)，局部检查与邻接候选数量有关，完整恢复 O(K)。**树对指定状态最短，不等于最终建筑路线全局最短。**

设加权状态 S、连接 E、驻留基地 P，单棵树 O((S+E)log S)，图 O(S+E)，两棵树数组共 O(P×S)。每方向仅 `int` 前驱/下一跳、`long` 真实车道、`double` 成本，20字节/状态；每场两树40字节/状态。共享图只读派生自唯一权威 Network。
