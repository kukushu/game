## 查询实际重复多少

沿用真实城市保存点`0110347D2BC4E40E8CD98E841EE92F62D675935D076A21AE58D7F7A5A9ADB6CD`，tick642633、536辆车，删除道路87。132次恢复尝试中17次真正寻路，全部成功并恢复Active；11返家、4货运、2服务车。不是新造三万/五万人场景，也不是最新F52现场。

| 统计 | 结果 |
|---|---:|
| 精确起点车道、位置、目标、方向组合 | 17个，零重复 |
| 起点车道 / 其末端路口 | 13 / 12 |
| 精确目标入口及位置 | 14个 |
| 目标入口551、555、600 | 各2次，其余各1次 |

| 无法到达的查询 | 0 |
| 原展开 / 不同展开车道 | 30,942 / 9,423 |

有相近起点：136对查询中，6对起点**车道末端**相距不超过10单位、19对不超过32单位、37对不超过64单位。CSV同时保留精确车道内出发距离；这些末端坐标不是车辆实际位置，不能据此声称相邻车辆输入相同。

因此：普通精确结果缓存没有命中机会；按精确目标建反向树会面对14个目标、只有3次额外复用。按11组目标车道进一步共享还必须正确处理不同停靠距离和两侧入口竞争，不能直接混用。没有不可达搜索可供提前排除。本轮没有建树，尚未测它实际盈亏，不能断言所有城市都不划算。

## A* 实际实现

`Tools/Diagnostics/RecoveryAStar.cs`是诊断用`Network` partial，仅由工具显式加入临时Player/模型测试。

- 复用权威`LaneConnection`、成本计算、车道起止裁剪、目标两侧判断、合法连接列表和路线还原方式。
- `g`代表到当前车道**出口**的时间。`h`使用出口到目标准确停靠位置的三维直线距离，除以全网最高速度；双目标取较小值。不能拿距离直接与秒相加。
- 一次性扫描当前Network的最高速度与几何接缝距离总和。启发距离扣除接缝总和，并保守缩小`1e-12`；本真实图接缝合计0。数学实数模型下，最高速度上界、折线长度和三角不等式给出下界；浮点边界仍需测试，不能据此承诺任意图的位级一致性。
- 独立二叉堆按`g+h`、ID排序，不修改原RouteQueue；允许更优g重开节点。`h=0`作为严格Dijkstra控制组。
- 仅复用队列/字典工作内存和两个静态标量，没有保存每个目标的路线树。Network对象更换自然丢弃实验状态。

## 正确性与限制

复用原FromLane夹具输入生成器，原测试文件保留不动：51,046组输入覆盖双向、单行、多车道、不同速度、断开图、零长度连接、等成本、车道内位置与边界，以及预热后拆分、升级、改速、删除、旧Network继续查询和冷读档。

- `h=0`的可达性、目标选择、完整路线与原Dijkstra严格一致，出现差异即失败。
- `h>0`独立检查所有非空路线合法性；**分类记录差异，不冒充完整等价断言**。51,046组中50,289组完整路线/目标相同，757组路线改变；目标、成本double位模式、可达性差异均0。工具同时保留数值误差带分类，但本次连成本位差都没有，未靠误差带掩盖差异。
- 真实17组：全部合法可达，入口和成本double位模式全部相同，2条完整路线相同、15条不同。车辆132512成本仍45.253189804293193秒，但第一个连接从`-25293062408644`改为`-25293062411970`，之后经过不同道路，并非统计口径变化。
- 这些等成本路线会改变车辆所在车道和未来路口预约、拥堵及到达时机；**没有验证A*控制的后续完整城市状态，也不能宣称模拟行为保持一致**。
- 实际城市仍用Dijkstra施工。3个Player的施工前、施工后及80步终态共9个完整存档与冻结基线逐字节相同；每次80个0.05秒冷热继续模拟相同、完整Validate通过，见`verification.csv`。这是“影子工具不改变城市”的验证，不是A*替换后的状态验证。
- 用户F52存档SHA保持`F52A46FEF07CE0E71BB0F5FEF6EF823400B74946FB9702E94C6DE51C777DB74C`。未重跑与零运行时代码改动无关的全部经济/居民回归。

## 下一步建议

优先继续A*，暂不加反向树。下一项应单独研究“如何减少无关展开，同时保留原Dijkstra的等成本路线选择”，例如用已验证的目标下界裁剪、再保持原g/ID父节点顺序；这需要另做证明和严格对照，不能认为简单修改堆排序就能兼得。

若将来明确接受等成本路线变化，也必须先让A*实际驱动车辆，验证批恢复安全、任务/货物/存档及后续模拟，再测真实施工帧。当前只建议保留研究工具，**不建议把本A*直接合入正式运行路径**。Network重建、空间Shape比较、分区几何等其余热点本轮未动。
