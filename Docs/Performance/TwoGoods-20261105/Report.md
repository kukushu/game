- 通知、消费访问、候选、队列大小及常驻快照可见；没有把各类通知CPU单独完全分摊的实验。完整步包含这些成本，不能把候选下降直接称作FPS收益。

- 普通窗口可证明城市运行和渲染，但不是鼠标建城、库存详情面板逐项视觉验收或长期健康经营验收。未经覆盖部分不标PASS。
