## 仍保留的轮询与扩展边界

本次接管的是通勤/返家决策，不是把城市所有业务都事件化。无法安全纳入资金通知的雇主类型、无效日历/特殊数值条件保守检查；真实重试仍按原.25秒请求。劳动/工资仍按固定步处理实际在岗人员；交通仍真实移动每辆活动车。人口就业每6模拟秒、日切迁入/统计，以及家庭购物周期、家庭消费等扫描继续保留：修改它们需要各自依赖审计与验收，MS018家庭候选曾无可靠收益，未偷偷启用。

调度稳定步主要成本为就绪决策、实际变化与到期事件；队列/稀疏插入 `O(log N)`，常驻 `O(N+依赖边)`。居民增删不再每次重建全体槽位，数组几何扩容、半数孔洞压缩、冷恢复及确有全局语义的日切/路网计划失效仍可能 `O(N)`。具备扩展潜力，不等于百万人实际活动/交通/内存已经可承受。

下阶段应优先对车辆移动、共享占用索引和车辆表现同步做新版本分项；不能把派车中触发的索引成本误判成剩余全员居民判断。其次单独定位周期性长帧，避免仅追平均值。本轮不擅自修改这些系统，不合正式分支。
