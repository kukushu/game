基线：`19e0c31f5462fde018194452e949d8f1a654cd9f`；分支：`codex/layered-presentation-20261102`。

阶段一：可选表现变更日志和车辆空间索引。日志只记录 ID，模拟提交入口标脏；没有消费者时不创建/积累日志。64/256/1024 单位区域统计、车道弧长区间映射均由显示读端拥有；不调用交通 EnsureIndex。普通前进查区间，变道、冻结和区间边界准确采样。换路网只检查已使用几何及其关联车辆。释放消费者时解绑。
