## 架构与局部更新

[完整所有权说明](../../Architecture/LayeredPresentation.md)。模拟提交入口只可选登记ID，帧末读最终事实，无消费者不积累。动态64单位网格向256/1024父级传播计数；普通移动查静态车道弧长区间，不为定位网格先采样全城精确姿态。变道准确采样并同时登记源/目标几何依赖；冻结用权威冻结点。几何等价的路网包装替换复用映射，拓扑变化仍核对缓存几何，不能声称编辑完全没有全局检查。

建筑不是原来每帧全量重建：原实现按版本同步，本轮保留这一事实。新路径消费局部变化，近景池化，中景64单位按用途合批，远景父块真实屋顶/占地轮廓。跨块物体以唯一中心归属计数、完整AABB向祖先扩展，因此不漏显示/拾取。父网格失效先退到当前子块，按软预算延后准备；单个Mesh构建不能中断，软预算不是硬帧上限。

质量阈值集中在HarborCityDisplaySettings：车辆12/10px近景、2/3px摘要，建筑24/20px、4/6px。共享每帧64个新个体/约1ms软预算，准备不足由批量表示覆盖；池化、边缘预取及滞回保持主体互斥。稳定ID选择和轮廓不依赖永久GameObject。暂停、旋转和分辨率变化照常查询；分区工具/施工范围保留全部格子。`-harbor-legacy-views`仅改变显示，不改变启动城市、资金模式或存档。
