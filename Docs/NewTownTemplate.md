# 新城基础设施模板

正常Play新建平地城市时，CityNewTownTemplate.Create用当前代码生成左侧边缘的一列基础设施，不读取历史存档，不给旧城补建或增加兼容迁移。原CreateEmpty、诊断/规模城市、已有存档读取入口保持原行为。

- 电站、供水、排污各24座，垃圾设施增加到8座，依次排成一个窄长列。普通设施中心x=-150，垃圾设施中心x=-148.5；较大的垃圾设施外侧边缘与普通设施对齐。中间预留间隔，让连接道路安全穿过。均为原有正常建筑，100%预算下电/水/排污容量各3840游戏单位，不是无限供应。
- 一条南北主路（x=-156）和一段中央短接路，全部双向各两车道（lanes=2）。保留原水电通道，向市中心的接入口为(-132, 0)，地面高度2。玩家接通一条道路后，服务按真实道路/管网覆盖和容量分配；断路、拆设施、预算变化继续生效。
- “水电设施 → 定位左侧基础设施带”可移动相机到接口附近查看。设施均避开中部建城区域，无新增水面或特殊豁免。
- 工厂只创建一个私有新session，经原道路规划/检查/提交、设施放置、入口注册和财政付款，再完整Validate后交给宿主；没有模板存档或第二套服务数据。沿用当前正常新城无限资金设置，费用仍入账；之后的维护和垃圾运输均走真实模拟。不预先推进时间、不生成居民/车辆。

验证：扩展原CityRoadUtilitiesChecks，通过3234项检查（含逐对设施不重叠、窄列坐标、双向各两车道、合法地形/道路入口、真实容量、初始时钟/居民/车辆、读取后完整状态与模拟、接路供给/断路断供、失败道路事务城市不变及原工具检查）。运行使用Unity内置Mono，最新原始日志/可视化在Temp/NewTownStrip-20261019*，之前的方形布局结果在Temp/NewTownTemplate-20261019*保留。隔离Unity编译及HUD Layout/Repaint、方格和分区回归通过，已查看真实相机渲染的预建区截图；不冒称物理鼠标验收或大城性能改善。已有历史存档无需参与这项功能。
