# 工厂生产第一版（存档 v6）

工厂复用现有建筑、岗位、居民通勤、货车与家庭住房选择。没有新企业账户、产业链或独立窗口。

## 生产与库存

- `CityBuilding.factory` 保存原料、加工进度、累计在岗/加工时间、产量及环境历史。成品仍使用 `TrafficState.stock[buildingId]`。
- 原料容量 24，成品生产上限 24。每件商品消耗 1 份原料和 60 个实际工人分钟；多人可以共同完成一批。
- 居民实际到厂、处于本人工作时段、持有该厂岗位且没有在途任务，才能贡献劳动。工资沿用在岗时间结算；缺料或仓满时有在岗工资，但无有效加工。
- 开始加工时领用原料，未完工进度存档。缺工、缺料或仓满期间不积攒未来可用的劳动。
- 工厂有雇员，且原料与已订在途原料总和低于 8 时，调度进口；每车最多 8 份。订货时不入库，到达后才入库。已有交通调度和拥堵会影响送达。
- 商业缺货优先向本城工厂提货，不足时进口商品；工厂库存达到 20 时也会尝试出口。发车从供应方扣货，到达才交付。回程不重复交货。
- 断路车辆等待；沿用货运 120 模拟秒失败期限。失败货物退回仍存在且有空间的供应方，否则计入 `lostGoods/lostRaw`。拆除的库存及在制品也明确记为损失。
- `produced/consumed/imported/shipped` 是累计计数；`shipped` 指装车发出的总量，包括之后可能退货的运输，不代表净销售或收入。

## 环境与住房

实际加工工人分钟产生噪声、污染强度，4 个连续加工工人对应强度 1；不依赖建筑岗位是否填满。噪声和污染分别以 60、720 游戏分钟的时间尺度衰减。按距厂 24、45 世界单位线性衰减至零。

住宅周围 12 世界单位内的实际货车（含排队和空车返程）形成重型交通暴露记录，以 120 游戏分钟平滑。停留卸货阶段不重复计道路车流。拆除工厂后残留环境记录逐步消退。

每户分别具有噪声、污染、货车敏感度。候选住房评分减去：`噪声×敏感度×18 + 污染×敏感度×30 + 货车暴露×敏感度×12`。原有房租、空间、隐私、通勤、储蓄和租约规则保留。环境只是取舍的一部分，靠近工厂不会被硬性禁止居住。

这些距离、加工配方、衰减时间和评分权重是第一版调参常量；环境数值是活动暴露指标，不是物理浓度。目前没有风向、污染健康损害、原料采购费、商品销售收入或企业盈亏。工资继续使用原有外部工资流，不从不存在的工厂账户扣款。

## 调试与日志

- F3 → 住房 / 岗位：工厂状态、原料、成品、当前加工进度、累计在岗与加工分钟、累计产量和环境强度。
- F3 → 家庭 / 决策：每户环境敏感度、候选住房暴露值及环境扣分。
- F3 → 导出日志：`factory.input/produced/raw_arrived/status/day/demolished`、`cargo.failed` 与原有居民、货车和住房决策事件。`factory.day` 含原料、成品、累计加工数据，可用相邻两日差值分析每日产量。
- 可检查：只有岗位无到岗者时产量为零；原料货车未到时无原料；移除出货道路最终仓满停产；重新开通后继续加工；不同家庭对同一环境的扣分不同。

## 存档兼容

v5 及更早存档经原有迁移后进入 v6。保留居民、岗位、住房、储蓄、既有成品和在途任务。旧货车缺少 `cargoKind`，默认仍为商品；新增原料库存从零开始。家庭环境敏感度按家庭 ID 确定性初始化，不推进原有随机序列。迁移重复执行不清空库存或进度。

保存当前批次、累计数据、环境历史和在途货物，读档继续生产。每步临时劳动累计不保存，每个固定模拟步结束后归零。无 Household 的旧版测试模型仍保留原来的简化产货逻辑；正常游戏均采用真实劳动生产。

验证入口：`Tools/Verify.ps1`；Unity 菜单 `Harbor → Validate household simulation` 另外检查真实 JsonUtility 序列化、加工中断后续算及旧档迁移。
