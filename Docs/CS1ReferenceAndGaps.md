## 规则切换边界

第一阶段只建立道路与规划土地，不同时扩展家庭经济。普通 R/C/I 分区工具不调用当前手动建楼入口；旧入口可以作为开发工具隔离，不能与正常分区生长并行决定城市。

第二阶段接入生长时，同步切换普通建筑生成、居民迁入条件、需求与财政来源，停用冲突的政府租金、私人建筑费用、工厂注资及其他未经确认的原创限制。保留微观实体、库存和交通任务，按目标规则调整行为。任何仍保留的近似模型必须写明差异，不能因为已有代码就成为本体规则。

人口由真实居民统计，就业由居民与岗位关系统计，入住由住房占用统计；财政和需求在规则确认后生成缓存。保留微观真实性不等于沿用当前自定义计算公式。

## MOD 单独对照

- TM:PE 作者资料说明其提供交通管理与车道使用等能力；车道连接器约束进入车道与驶出车道的连接。实现前须先有车道数据和实际通行模型，不能在当前单线道路图上只加按钮。[作者文档](https://doc.tmpe.me/home.html)、[车道连接器说明](https://doc.tmpe.me/lane-connectors.html)
- Network Anarchy 作者说明其整合 Fine Road Tool 与 Fine Road Anarchy 的能力，包括高度步长、施工形态及限制调整；这只是用户所指修路 MOD 的候选，不代表已选定。[作者 Workshop 页面](https://steamcommunity.com/sharedfiles/filedetails/?id=2862881785)
- Network Multitool 是另一个待确认候选。确认身份后再逐项查作者资料并列验收，不自动加入所有候选功能。
