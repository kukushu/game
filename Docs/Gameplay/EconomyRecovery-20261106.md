# 小城循环修复记录

## 第一阶段：经营判断与就业恢复

基线 `c9d5122`。工厂扩建判断加入一班次的供给上界，受真实原料（含在途）、现金、健康合格员工、仓容和水电限制；同一份供给在不同商店之间仅分配一次。上界不是保证交付，运输或营业窗口仍可能使其落空。

企业无钱且没有在途货运时，已回家、无携货、无活动任务的员工释放岗位，保留已赚工资。求职先给没有资金正常的雇主岗位的家庭一次机会，再分配额外家庭劳动力；不强制改动已有工作，不招用生病居民，实际岗位仍按技能和路径选择。

两商品专项 1,254 项通过，包含新增恢复边界、在途回款保护、家庭求职优先和共用供给检查，保留参考轮询/事件版及冷恢复对照。核心回归通过 20,960 项产业/居民、10,000 岗位索引、1,522 网格、83 分区、460,474 水电检查。检查计数包含运行路径中的断言次数，会随模拟行为改变，没有删除或放宽原断言。

以下为 Unity Mono 固定步结果，均有真实进口道路，没有修改初始物资或中途注资。生长城人口随决策变化，不是同人口配对。密集 120/502 人为预置多企业压力场景。

结论仍是经济验收失败。交易增加不能证明持续经营。独立的一人企业 SmallBusiness 候选（早于家庭求职优先改动）到 90 天有 9/11 户断粮，三家企业均有现金；缩小企业规模不能单独解决家庭收入。

`Tools/RunSmallEconomyStudy.ps1` 新增 SmallBusiness 候选与末态逐户 `households.csv`。原始结果在 `Temp/EconomyRecovery-20261106-*`，各目录有输入源码哈希、每日资金流水、末态存档和日志。旧城不被覆盖。

## 下一阶段：开放城外市场

用户已选择开放城外市场，明确记录外部付款，以订单量和实际运输限制成交，不模拟整个世界固定钱包。第一阶段 Pilot 到 90 天城外仅余 104 元，已不足部分整车出口订单；此前固定 100,000 元钱包不适合作为这个边界。后续将实现按品类外部订单与在途预付账，不能只移除余额检查并无限发货。尚未完成本阶段及其验证。
