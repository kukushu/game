# 当前玩法实现快照（2026-11-04）

本文件说明已经运行的原型行为，不代表用户认可这些规则，也不把它们升级为未来设计约束。核对正式工作区 develop，源码提交0342fde；本次只读源码，没有运行新的玩法测试。核心玩法讨论与确认见[CoreLoop.md](CoreLoop.md)。

## 居民与家庭

- 居民事实包括年龄、劳动能力、技能、岗位、位置、通勤/购物任务、到岗状态及工资。家庭持有储蓄、住址和当日购物状态。日常收入、付款、位置、在岗和出行状态实际变化。
- 正常迁入用ID公式生成2—4人的家庭、年龄、技能与初始储蓄，尚无自主择业人格生成。技能影响岗位门槛，年龄影响成年就业/购物资格。
- ageProgress、教育、医疗等字段存在，但当前CitySimulation正式运行链未接入完整自然老化、出生、死亡、教育成长和医疗循环；CanAttendWork只核对劳动能力与生病标志，不能凭字段存在宣称玩法已运行。
- 家庭空间、隐私、储蓄、通勤、环境敏感偏好有保存字段，但本次检查当前正常决策链未发现其参与选择。不同储蓄意愿的自主消费尚未实现。

## 迁入、住房和工作

- CityCorePopulation按日寻找未废弃、未着火/烧毁、有道路和完整基础供给的空住宅单元，按建筑和单元顺序填入家庭。默认每日最多2户（实际设置可能不同），每户初始储蓄450 + 家庭ID%7 × 100。
- 迁入不预检可获得工作、租金负担或个人居住偏好；新住宅当前租金为0。没有当前人口自主搬家、因失业/贫困而迁出的完整运行流程；实体维护接口不等于自主迁居玩法。拆除有人居住的住房当前明确拒绝，要求先有迁居策略。
- 求职筛选有空位、雇主有钱、道路接入、技能符合的岗位，在可达候选中选预计通勤时间最小者；同成本按岗位ID稳定选择。已就业者不参与主动比较工资或跳槽。
- 工资和班次来自配置及ID规则，不是雇主报价竞争。工作必须真实出发、到岗，并在工作时段贡献劳动；路途耗时影响实际到岗和收入。雇主资金不足限制付薪和工作资格。

## 建筑选址与需求

- 玩家划定用途，CityCoreGrowth每6模拟秒检查增长。对有正需求且无同用途待建项目的用途，按预设占地形状及分区格序寻找可建、可接道路入口、无重叠的位置，建立约12模拟秒后完成的项目。
- 工厂与商店不是独立企业家根据租金、顾客、利润或供应链主动选择位置；建成后没有自主迁址流程。
- 住宅需求=clamp(70−空置住宅单元×12+空缺岗位×2−失业人数×4,0,100)。
- 商业需求=clamp(30+人口×3−商业岗位容量×6,0,100)。
- 工业需求=clamp(40+失业人数×8−空缺岗位×8,0,100)。
- 上述是预设宏观估计公式，商业需求尚未来自逐户未满足消费或真实企业利润。

## 商品与资金

- 正常链路为城外原料→工厂加工→货车配送到商店→居民实际到店付款→带回家计消费；工厂也可以向城外出口多余成品。当前没有工厂直接零售给家庭的流程，也没有完整多品类产业链。
- 工厂要有原料、实际付薪劳动、加工费和库存空间，并满足运行条件才生产。商店承担商品中转零售、就业和工资支付，不只是区域装饰。
- 本地批发发车成功时商店预付货款、工厂扣货，货物运输中；交付成功后商店入库、工厂确认销售收入。不能把发车扣库存当成交付。
- 居民购物要有可用成年人、足够家庭储蓄、当日尚未成功发起购物、到达购物时间等条件。购物成功发车时标记当天已购物，不以最终成交成功为前提。选择近距离且可达、有货、实际有人工作及供给完整的商店。到店按实际库存及支付能力购买，家庭扣钱、商店加钱，商品由居民带回家后计消费。
- 默认配置零售价60/件、每次最多3件、17:00开始购物检查，批发价45/件、原料8/份、加工成本2/件；实际城市使用其保存的规则快照，不保证所有存档数值相同。没有个人储蓄率或商品偏好驱动的需求预算，也未实现自由市场动态定价。
- 工厂与商店从各自现金支付实际在岗工资，先形成个人工资余额，日结将整数转入家庭储蓄、保留小数。家庭购物及税费会真实扣余额。
- 税款从家庭和企业实际余额转入市财政，但计税基础仍是人口/被雇员占用的岗位数对应的预设税基，并非完整收入税或利润税。公共设施维护费、生产加工费等是已记账支出，没有完整模拟每个收款方。
- 经济不是封闭自生系统：新家庭带入初始储蓄，新生工厂与商店直接取得配置中的初始经营资本（当前增长入口未从投资者或财政扣对应资本），城外有独立市场账户，城市有初始财政/贷款/补助。
- 普通玩家入口默认开启无限公共资金，公共建设/维护等以补助规则支持；这不等于家庭、工厂或商店有无限现金。不能把财政∞误认为居民买东西不扣钱。
- 因此：账户、工资、交易与库存有实际状态和核对机制；人口需求、生成、定价、资金来源及部分支出仍是简化设定，尚未达到全部宏观结果由微观决策涌现。
