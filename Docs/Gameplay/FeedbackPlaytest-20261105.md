# HarborCity 反馈试玩 v1

这是两类商品实验分支的手动试玩包。经济、购物、投资参数和存档格式保持原规则；已知企业资金耗尽、供给停摆仍可能发生，本轮负责把事实和现场交给玩家。

## 如何试玩

1. 打开同目录的 `HarborCity.exe`，保留整个 Player 文件夹。默认进入原有正常新城，不自动加载诊断现场或日常版本存档。左下显示试玩版本。
2. 顶部“城市提醒”显示食物、日用品库存用尽/储备偏低家庭数、资金耗尽商店/工厂数及基础设施问题。窄窗口会收起。点击进入按严重程度与类别分组的清单，再点击住宅或企业定位。
3. 点住宅后展开家庭，可看到库存、支撑天数、补购需要、可采购成年人、采购进度及供应商定位。点企业可看到现金、岗位占用、实际在岗、最近模拟步获付薪人数及自开业累计账目。正常夜间无员工不会单独生成城市经济警报。
4. 看不懂时，点击详情面板或底部“游戏”菜单中的“暂停并记录现场”。记录后保持暂停；保存位置会显示，并可打开文件夹或复制路径。
5. “游戏”菜单另有“商店资金耗尽”和“城市供应停摆”两个已有问题现场。选择后可先保存当前城再进入，或明确放弃当前未保存进度。现场按原诊断平地加载并保持暂停，请自行选择倍率开始观察。它们只是历史问题样本，不能当作新城或修复成功证明。

## 存档与记录

试玩产品名为 `HarborCity Feedback Playtest`，独立数据根目录：`%USERPROFILE%/AppData/LocalLow/DefaultCompany/HarborCity Feedback Playtest`。不读取、覆盖日常 `test` 产品目录。普通存档保留原 `.hcity` 协议，试玩额外的 `.view.json` 是平地视图说明和文件哈希，不改变城市格式；普通存档与说明文件应一起保留。

每次现场记录新建 `IssueSnapshots/时间-随机标识` 文件夹，包含：

- `city.hcity`：在原保存边界允许时写出的当前城市副本，不覆盖普通存档。
- `scene.json`：源码提交/资产指纹、构建时间、城市 Tick/欠步、问题类别/对象/观测证据、选中建筑、家庭与居民详情、错误信息。
- `window.png`：当前游戏窗口截图。截图包含游戏画面，不包含桌面其他窗口。

若模拟已故障或无法合法保存，会明确显示“现场记录不完整”，在 `saveError` 中保留错误；能取得的 JSON 和截图仍保留。不会绕过保存校验、不自动上传。恢复模拟前请先保留记录；单纯打开详情不会推进模拟、购物或重新选供应商。

## 你来验收

- 正常新城的初始准备、正常补购、夜间停业没有被描述为经济故障。
- 缺食物能从提醒进入受影响住宅；在岗、店内有货但无人付薪、商店没钱分别有原因说明。
- 现金下降能对照累计工资、采购、加工和税费，累计值没有冒充“今日利润”。
- 问题解除后清单消失；读档、换问题现场后没有旧城残留。
- 记录后仍暂停；存档、JSON、截图相互对应，日常存档不受影响。

本轮只做代码检查、模型编译、Unity Release 构建和产物核对；没有启动 Player，没有运行回归、模拟、性能或自动交互测试。上述运行表现、按钮可用性、截图和故障记录路径均须由玩家手测确认。请把仍看不懂的情况直接记录现场，用于下一轮规则修复。

源码/构建精确信息见包内 `build-manifest.json`；本说明不会用旧报告的测试通过替代本轮验收。
