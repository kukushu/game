# 50倍降速修复（2026-10-20）

问题：按钮能改变目标值，但宿主每帧仍允许最多32个完整步。50倍运行积累的 pendingSeconds 会继续按CPU预算追赶，切回1倍也可能高速推进。基线源码 5b95112；固定60帧、每帧1/60秒输入的模型复现中，先积累49.95秒欠步，目标1倍后仍推进50.95模拟秒。这是受控输入回放，不是旧Player帧性能实测。

修复：CityPlayerStepBudget 只拥有渲染宿主的有界执行额度；切倍率重置额度，按新倍率累计允许的步数，仍受32步/8ms协作预算限制。全部请求时间经 CitySimulation.RequestTime 写入原唯一保存时钟，不够一个固定步的帧只入队；原 Advance 的正步数约束、故障和重入检查保留。不清空欠步、不跳步、不改0.05秒步长或居民/车辆/经济规则。读取城市重置宿主额度，存档结构不变。欠步多时降低倍率会按新速度处理最早的未完成步骤，不再额外超速追赶。
