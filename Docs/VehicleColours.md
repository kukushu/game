# 按出行用途显示车辆颜色

货运（含原材料、商品、进出口）使用工业分区橙黄色；上班和回家使用住宅分区绿色；购物使用商业分区蓝色。垃圾服务继续使用原默认材质。色值由HarborCityZoningViews.Colour统一提供，道路宿主创建分区材质与车辆显示读取同一份表现配色；建筑自身材质和所有分区几何不变。

HarborCityVehicleViews仅拥有三份新增共享材质，每辆车绑定显示对象时按原Task.purpose选材质，包含从池里复用的对象。没有每车创建材质、每帧改色、模拟写入或新车型/物理尺寸。换World清理显示但保留配色，Dispose释放自有材质，传入的原材质仍由宿主持有。

复用Tools/Diagnostics/HarborCityVehicleViewValidation.cs，在隔离Unity Editor批处理通过15121项检查：3000实际交通夹具车辆全部显示，位置/方向/尺寸/碰撞器与稳定对象一致，原12轮货运结算复用通过；额外覆盖五类用途及跨用途连续复用、四份实际使用共享材质、来源材质不被改写、每次Sync前后完整交通保存逐字节一致。测试中的分用途路线使用独立交通夹具，完整业务城市规则未修改。原始结果在本地Temp/VehicleColours-20261019/Result.txt，Unity日志Temp/VehicleColours-20261019.log。

未做本批真实玩家鼠标或大城Player性能配对，未重建独立Player；这是显示配色变更，不宣称FPS提升。
