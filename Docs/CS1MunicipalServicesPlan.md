# 一代基础市政服务接入顺序

居民生命周期与年龄、升学、退休、死亡的关联改造见 [下一批方案](CS1PopulationLifecyclePlan.md)。年龄、退休、三段教育和建筑内死亡/墓地/真实灵车基础已实施，出生、途中死亡、火葬与墓地清空仍未实施；年龄单位和速率须逐项核实，不把受控年龄边界或死亡事件测试当作完整成长体验。

死亡服务目前保留具体历史居民与遗体，实际接取和送达才变更库存；断路、停电、满容量与途中重载有专项检查。默认 48 个墓位、2 辆灵车、建设 4000、维护 60、复用医疗预算和风险/废弃速率是近似目录。有遗体的建筑和已占位墓地暂不能拆除，转运与火葬完成前不允许丢失死者；这个限制不是已核实的原作规则。详情和独立版本证据见实施进度。

本轮接入土地价值与建筑升级基础：实际居民教育、可达服务与环境条件支持稳定实体升级，空住房和新岗位由实体增加，工业产量继续依赖真实劳动和物流。参数与容量目录为待核实近似；完整教育规则、生命周期、完整服务覆盖、解锁与正式发展仍须推进，不能把当前自动升级当作完整成长流程。验收证据与差距见实施进度。

总路线继续执行；不用新的逐阶段确认。已经接入垃圾、独立供给、服务预算和实体信息视图。医疗、基础教育、消防和警察基础已接入，后续补死亡处理、土地价值与发展进程；解锁按原作基准核实，当前开发沙盒的全工具可用不能算标准发展流程完成。

## 依据与边界

一代官方手册 Healthcare and Safety 页说明：诊所和医院接收病人，救护车运输，无可用救护车时居民尝试步行到最近医疗设施。Education 页区分儿童的小学、青少年的高中、年轻成人和成人的大学。健康和教育影响工作、城市发展，服务不能只有模型。[官方手册](https://cdn.akamai.steamstatic.com/steam/apps/255710/manuals/CitiesSkylines-UserManual_EN.pdf?t=1426004897)

手册不能确认病发概率、治疗速度、准确容量、费用、年龄转换速度、教育完成时间、具体地图解锁人口，以及日夜预算响应。实现参数须标为近似，实际规则逐项核实；不加入股东、家庭医疗保险、私人择校或原创教育经济。

## 最小医疗改造

以下最小流程已接入代码并通过实体模拟检查：个人健康与患病状态、保留岗位但停止实际劳动、独立诊所、有限预约与实际患者、救护车接人送医、无可发车辆时的真实步行、实际治疗、步行返家、医疗预算与诊所详情。独立版本和视觉验证记录在实施进度文档中；不能把这些检查当作原作完整医疗体验验收。

明确的当前差异：健康使用每日实际位置采样，病发阈值 40、恢复目标 80、环境权重和治疗速度为近似；诊所默认 8 个位置、2 辆救护车、建造费 10000、每日维护 80，以及预算线性响应都尚未核实。步行沿道路路径、在路旁显示，不是完整人行道与过街网络。当前治疗后的返家统一步行，原作返程方式待核实。诊所有关联患者或车辆时暂时禁止拆除，这是保护未完成的患者安置逻辑，不能宣称原作也有此限制。医院、服务解锁、污染水源、长期健康与死亡处理仍待接入。

1. 在既有 Citizen 上保存健康、是否患病和治疗位置。疾病影响实际工作出勤，暂时患病保留就业合同；人口、在岗人数、病人数量分别从实体统计。健康的环境输入使用现有真实垃圾与工业活动记录，具体速率仍待原作对照。
2. 增加独立诊所建筑与有限患者容量。患者必须属于本城真实家庭；床位占用与预约分开，实际到达才进入治疗。道路和供给不可用时不能制造治疗结果。
3. 在现有交通中实现有限救护车，从诊所出发、实际到住处接人、运到诊所，再计治疗。住宅拆除、诊所拆除和断路需要保留或明确释放关联，不能把人直接瞬移到设施。
4. 增加真实步行模式，支持无可用救护车时的原作步行就诊后备。步行与车辆通行分开，不能用一辆蓝色车宣称实现步行。就诊、治疗、返家都可由既有成员观察与目的地定位查看。
5. 接入医疗预算、详情与信息视图。费用和床位、车辆由实际诊所及预算统计；保存病人、预约和途中救护车后必须可靠恢复。

可重复验收：服务不足出现真实患病居民 → 建诊所接水电与道路 → 实际救护车接人或步行就诊 → 到达后才治疗 → 居民返家并恢复出勤；中途断路、拆设施、保存重载，核对每名居民位置和每个床位、车辆。禁止仅把健康宏观值设为 100 宣称完成。

## 基础教育与后续服务

小学已接入实际儿童与有限学位，区分入学、到校、实际学习、个人课程完成与返家。患病与供给不足暂停学习；道路中断保留途中儿童；学校拆除释放学位并让学生从实际道路位置返家。既有成员观察和学校详情展示真实状态，预算限制新入学人数和维护支出，降低预算保留已入学儿童。模拟检查与独立版本已验证实体关系、原生 JSON 在校保存和连续多日上课。

当前使用 6–13 岁、24 个默认学位、8:00–16:00 课堂、7200 分钟个人实际学习完成小学课程，建筑费 10000、默认每日维护 60；这些都是待核实的原型参数。毕业只修改真正完成课程的个人教育，并使其技能至少达到 1；既有成人技能种子仍保留，不能当作原作教育层次的证据。儿童完成课程仍不自动成为劳动力。当前年龄已推进；超过阶段年龄释放学位并实际返家，高中/大学有独立课程和有限学位。后续需对齐完整生命周期、教育选择、课程节奏与岗位教育门槛、建筑升级和服务解锁。不加入学费经济或原创择校偏好。

可重复教育验收：发展出有儿童的住宅 → 建小学并接通道路、水电与排污 → 查看实际入学与步行任务 → 到校才增加个人学习 → 结束上课后步行返家 → 连续上课达到课程要求 → 保存重载核对每名学生、学位和学习记录。中途断路、停供、学生患病及拆校均核对实际位置。没有完成原作同场景操作、人口生命周期和真实人行道对照，不能将当前实现标为原作完整教育系统。

消防以真实火灾、有限消防车与实际处置为核心，警察以实际服务能力和事件处理为核心；死亡处理使用真实死者、灵车和墓地容量。垃圾库存与服务车辆已实现的派车、道路中断、设施清空和不可拆除规则可以复用，但不同服务不能共用“货物数”来冒充居民或死者。

消防基础已接入：真实建筑火势/损伤、有限车辆、实际到场抑制与返程、烧毁住房/岗位释放和废墟保存，不能自动按普通废弃恢复。复现流程：接通街区与消防站 → 城市继续发展出现自然火灾 → 观察车辆实际出勤、到场和返程 → 对比断路时火势与损伤 → 烧毁后拆除并重新开发 → 保存读取核对车辆、火场和废墟。受控自动场景主动点火以验证这些关系，正常游戏使用自然事件，未新增手动灾害按钮。近似参数和未实现的预防覆盖、蔓延、公共设施火灾、撤离与视觉见实施进度；原作同场景游玩仍待验证。

每一批均验证实体关系、普通城市回归、新存档和独立版本；实际游玩与原作同场景比较单独记录。所有尚未核实的常数和视觉占位都保留在差距表中。

警察基础已接入建筑犯罪积压与有限实际警车。实际到场后处理，断路和停供保留原车与积压，返程释放车额，预算/健康/存档均接入。原作失业与幸福感影响犯罪有手册依据，当前公式和以服务缺失代理幸福感属于近似；巡逻、预防覆盖、交通事故、土地价值和完整治安后果仍须补齐。监狱转运属于 After Dark，未纳入未指定 DLC 的基准；未加入二代个体犯罪者追逐。下一批继续死亡服务、土地价值、发展与解锁，不能把当前全工具开放沙盒当作完整一代开局。
