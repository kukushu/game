# 分类游戏界面

底部仅保留六个分类按钮，进入城市时不展开。点击分类打开最多420×300的可滚动面板：

- 道路：普通修路、单双向与车道设置、方格路网、道路编辑/拓宽/拆除。
- 分区：住宅、商业、工业、清除，沿用框选/点选设置。
- 水电设施：电站、供水、排污、垃圾设施、手工管线及设施旋转。
- 对外贸易：连接、进出口定位、贸易与仓库数据。
- 城市观察：问题列表、财政、岗位、项目与模拟待处理时间。
- 游戏：保存、读取、临时无限资金。

右上角实时读取真实居民实体数、活动车辆数、资金与模拟时钟；暂停、1×、3×、20×仍走原固定步与每帧预算。显示目标速度，不保证大城市实际达到对应倍率。

再次点击当前分类或“收起”关闭面板，保留已选择的地图工具；换分类取消旧工具及未完成手势。Esc取消并收起，底部仍保留当前工具及施工反馈。道路编辑和建筑观察详情放在右侧状态栏下方。原模拟、财政、存档、施工事务与分区命令不变。

验证：在现有隔离Unity批处理 `HarborCity.CityRoadGridToolChecks.Validate` 中检查分类开合、跨分类取消、真实输入排除区域、关闭后旧菜单位置可操作、操作前后完整保存相同，并为全部页面发送真实IMGUI Layout/Repaint事件；原方格道路与住宅/商业/工业框选回归通过。`python Tools/VerifyGameData.py` 检查中英文Key及参数一致。

这些属于程序化检查，不代表物理鼠标验收；没有进行性能配对或宣称帧率收益。改动适用于Unity源码运行，独立Player未重建。停止Play、等待编译后重新Play生效。
