# 道路自带水电

正常Unity Play新城、正常读档和手动inspect默认开启：所有道路都作为供电、供水/排污传输通道，普通道路、方格路网均适用。道路连接、拆分、拓宽、反向及拆除后通道随实际路网更新；单行交通不限制管网流向。电站、供水站、排污设施及实际容量仍必须满足，不凭道路生成电力、水或排污能力。临时无限资金设置继续有效。

道路通道包含在当前道路建设/维护价格内，不自动购买第二套手工管线、不额外扣费。供水/排污设施沿路自动接入最近的道路管网；每个设施只选一个自动道路分量，防止向两座断开的路网重复输出容量。手工管线保留独立事实，可在实际相交/接触处接入道路通道，拆路不删除手工管线。

唯一事实仍是World.Network的真实道路和CityUtilityState的手工管线。CityRoadUtilityConduits在已有UtilityLayout静态覆盖计算中投影道路与手工管线，复用CityUtilityCoverage空间索引查相交，只生成只读覆盖图/连通分量；该图不保存、不模拟车辆、不单独编辑、不创建额外Renderer，也不画会虚假供给沿线建筑的跨区连接线。World的立交交叉没有共享路口就不会自动连通；手工管线与建筑覆盖仍遵循现有二维管网规则，没有新增水压或高程水力模型。

道路规则以CityUtilityState.roadConduits保存，新增存档格式17。读取器保留对实际格式16的精确支持，仅为旧CityUtilityState补默认false，不放宽其他字段检查；纯模型读旧城保持原手工管线规则，玩家正常打开后明确启用新规则。存档文件路径保留便于继续读取，新的17文件需使用新代码打开；原输入存档不改写。静态覆盖缓存按原管网内容、建筑几何、道路Network身份和规则失效；建设/拆路成功后刷新实际供给，失败前不写管网或补扣款。

验证：23469综合城市、10000岗位索引、1518方格路网、83框选、3001原管线覆盖索引检查通过；道路水电35项检查覆盖单行不改交通、立交不误连、手工中点接入、近邻不误接、拆路立即断供/原路重建恢复、拆分/拓宽/反向、无手工管线的真实住宅生长迁入、预算和停运设施、失败施工全保存不变以及2500步完整状态续跑。另用既有三万人繁忙格式16存档完成旧规则读取、17往返及启用道路通道后的完整冷恢复，共39项专项通过。原城市文件未改。

Unity批处理已确认正常启动默认启用，并通过实际方格拖建、框选的程序化处理器与渲染检查，日志在Temp/RoadUtilities-20261018.log。不是物理鼠标验收，没有做新规则三/五万人Player性能配对，未声称提高FPS；比较性能时必须采用同一roadConduits设置。本批只更新Unity工程，没有重建独立Player或重新打包历史采样。
