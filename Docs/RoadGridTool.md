# 方格路网工具

在 Unity 停止 Play，编译后重新 Play。点击“方格路网（拖拽批量修路）”，选择街道间距，在地图上按住左键拖出矩形，松开施工；Esc 取消。沿用上方“单行”“每方向两车道”设置，单行街道交替方向。

间距为中心线距离，可选 24、32、48、64 米；默认 32 米。横纵尺寸向下取整到完整街区，支持四个拖拽方向，每次最多 8×8 街区。范围裁到地图建造边界。黄色预览只是几何示意，放开后才检查实际拓扑、车辆安全、建筑/待建项目与资金；不能把黄色当成批准施工。

整片路网共用一个私有道路草稿，通过原 RoadEditPlan 一次提交、一次扣款。不是逐条提交后再尝试回滚；最后一条路失败也不会留下前面的路。已有路口连接、交叉拆分仍由原连接算法处理。起点在3米内吸附已有路口；共线且三维中心线一致的已有路段按距离区间复用，只修缺段，保留原路宽/方向/速度，不重复扣款。完全重复范围明确提示无需施工。仅方格工具启用该策略，普通单路的重叠拒绝规则不变。

修复了“完全重合被拒绝、稍微错开却能建重叠路面”的问题：未覆盖的新路段还检查与已有平行道路的间距，按现有车道偏移与路面宽度拒绝相叠的道路走廊，正常横向交叉继续由路口算法处理。失败/资金不足/拖拽过小/菜单上松开等原因持久显示在方格工具下方，避免原notice埋在菜单下方。旧地图已存在的重叠道路不自动删除。暂不提供旋转网格、弯曲边界或自动绕障碍。

所有者：CityRoadGrid 只生成当次笔画；HarborCityRoadGridTool 只持拖拽状态和复用预览线；World/RoadEditPlan 仍独占实际拓扑与车辆迁移，Construction/Finance 独占付款。取消、切换工具、失焦或在菜单上松开不会施工。预览不创建完整世界草稿、不推进模拟、不扣款、不保存新事实。原城16存档格式与固定0.05秒步不变。没有第二套道路数据或全局管理器。

验证：150936 道路核心、23461 综合城市、10000 岗位索引检查通过；专项1518检查覆盖四向/四间距、8×8实际拓扑、两车道/交替单行可达、晚段重叠整批失败、资金不足、过期方案、在途车辆/任务/库存/时钟不变及完整存档续跑；新增共享边扩建22道路/15路口与4267单次费用、重复建设不改城、0.4/1.5/2米偏移平行重叠拒绝、部分中心线覆盖与原单行双车道属性保留。Unity 批处理检查了实际拖拽处理器、六条复用预览线、预览不改城、2×2网格实际显示、5120费用只扣一次、松开清理及取消，并验证略偏起点吸附后扩建、重复拖拽不扣款、平行重叠与过小拖拽的持久提示。模型测试接入现有 Tools/VerifyCityCore.ps1；Unity 检查入口 HarborCity.CityRoadGridToolChecks.Validate，需在隔离批处理项目执行。
