# 道路中途建筑入口（批次C）

起点cf2b592。生产业务不再保存Junction入口字典/CityCoreEndpoint转换；RoadAccess在World内拥有唯一endpoint→lane/distance/权限/有效性事实，原建筑entranceX/Z仍是实际门口坐标。原门口到车道的短 driveway 动画尚未做，当前是门口请求等待安全车道插入；不是从任意道路中心忽略占用生成车辆。

车辆起步在源访问点，末段停止在目标访问距离；route不展开样本点。新堆搜索支持部分首尾车道、同车道下游直达，以及同车道上游目标必须绕实际有向回路；不倒车或凭空U转。步内仍携带剩余时间跨Connection。

中途插入采用有序局部车道桶的二分位置及两侧安全间距，批量调度不会每次重建全城索引：固定步后标记脏，首次请求重建一次，然后局部插入/预约；静态来源/目的业务状态按原building ID查询。AccessUse表达货运/居民/服务权限，本批实际执行仍只有货运。

拆分规划中迁移入口的有向距离、所有当前车辆、路线末段与目标距离，保持世界位置；目标位于前半段会截短路线，不误驶向后半段。反向拆分同样按反向起算。拆除入口道路会清零失效车道引用并保留valid=false，Dispatch拒绝，CityCoreIndustrySession.AccessIssue给业务/表现层明确原因。业务实际门口不复制进交通。

核心存档格式3、组合城市格式2；旧开发格式明确拒绝，不写迁移器。RoadAccess随核心保存，城市原建筑与账目随业务保存。城市默认工厂/商店入口在道路10/25单位处，不新建两个楼的路口。

验证：543内核检查、244真实工业检查；包括1000个入口不增加节点、正反向首尾范围、前/后车阻止插入、同路逆向目标绕环、入口权限、曲线/高程既有检查、正反向/前后半目标拆分、断路无效入口、保存继续与真实工业双路拆分。Unity正常默认行业入口实车/跨渲染帧/编辑后保存验证通过。1000/3000固定车矩阵仍约0.3/1ms；行业模型当前2–4货车/4工人，路线缩短，不能与B场景直接当等价配对。

限制：未实现楼的自动选侧/多门口选择、真实停车场/driveway、入口变更时在途重新路由、居民/服务任务、任意位置施工或多车道。入口数量测试没有冒充完整1000楼城市。下一批D收拢事务并支持非样本位置拆分、同层交叉及高度隔离。
