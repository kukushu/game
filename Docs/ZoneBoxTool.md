# 分区框选

选择“划住宅区”“划商业区”“划工业区”或“清除分区”，默认使用“矩形框选”。左键按住拖拽、松开统一划区；Esc、结束划区、换工具、失焦或菜单上松开会取消未完成的选择。可切换“点选”保留原半径3米点击行为；框选模式不拖动的轻点也沿用该范围。

选择规则沿用旧界面已有的世界坐标矩形：分区格中心点在框内即选中，边界包含在内，支持四个方向。仅选取原 CityCoreZoning.Cells 的合法道路旁格子，不凭空增加地块。R/C/I框分别显示绿/蓝/黄边框，清除为白框；显示预选格子数，松开时重新查询当前格子后调用原 Paint。已有建筑和待建项目仍受原规则管理，不直接拆建或跳过模拟。

HarborCityZoneBoxTool只拥有输入手势、可复用的边框和临时格子引用，预览最多每0.1秒查询一次，释放时强制刷新；不逐帧重建分区Mesh或写事实。CityCoreZoning.SelectRectangle只做只读选择，CityZoningState仍是用途唯一来源，Paint逻辑、固定步和城16存档格式未改变。切换分区用途/加载城市会取消旧手势。

验证：23461综合城市、10000岗位索引、1518网格道路检查及83项框选专项通过。专项覆盖四方向、R/C/I与清除、边界、空范围、选择只读、与原逐格Paint完整状态相同及80步存档续跑。Unity程序化处理器检查通过R/C/I边框预览、松开提交、取消、清除和空选提示；本地日志 Temp/ZoneBox-20261018.log，截图 Temp/ZoneBox-20261018/zoning-box-preview.png。这是程序化输入处理器验证，尚未作物理鼠标验收或三/五万人性能配对，没有更新独立Player。Unity工程停止Play、编译后重新Play可用。
