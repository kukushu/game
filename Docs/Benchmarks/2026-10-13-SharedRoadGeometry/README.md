# 第三阶段共享几何批次

普通 Editor/Player 的 RoadView 端点和 SurfaceHeight 已读取版本化 RoadCenterline 的 xyz、结构剖面及平面投影；横坡继续叠加原地形高度，节点填充、标线、支撑、隧道可见性和原遍历顺序不变。缺失实际边时保留旧节点计算回退（旧调用也可能测量非相邻点）。独立结构负责投影，渲染不拥有另一套可编辑道路真相。

仍按旧 span 顺序构造 Mesh；路面自身每0.5单位细分不创建新交通节点。这不是已经删除施工产生的几何 RoadNode/RoadEdge，也不是新的样条平滑或视觉重做。车辆当前仍按原短边移动，完整第二/第三阶段尚未结束。

## 正确性

扩展的纯模型 oracle 逐方向核对横向投影、端点外夹取、高程及 Ground/Elevated/Tunnel；全量模型回归通过。普通 SampleScene 原生构建、运行通过道路施工、拆除、桥隧、行人、车道、路口、货运/服务和原生存档。

显式原生测试实际先用旧方式重建、再用共享几何重建，比较**活跃**游戏 Mesh 的名称/所有顶点/三角形SHA256，完全相同；地形横坡和端点高度逐值相同，车辆平滑坐标和整个JSON不变。只统计活跃对象，因为Unity Destroy在帧末才销毁旧的已隐藏几何。控制开关仅测试使用，finally复位；正常游戏默认共享几何。
