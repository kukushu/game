# 第三阶段施工批次：一笔曲线一份私有草稿

直线施工仍复制一次；曲线预览先复制一次，后续每个短段在独占草稿上执行原碰撞、交叉拆分、角度、费用及版本逻辑。枚举既有边时保存浅列表，以免拆分修改正在枚举的集合。失败只丢弃草稿，真实 CityRoads 不受影响；成功仍由原 CommitRoad 一次替换并按原 ApplySplits 迁移车辆。私有方法拒绝在 city.roads 本体上启用草稿模式。

这不是局部增量道路网络：每段仍扫描既有边、重建邻接；现有几何细分数量、短边 IDs、笔画、价格、Undo 和拆除规则不变。CITY_ROAD_PLAN_COPY_PER_SEGMENT 可回退逐段复制。

## 正确性

- 同一源码编译旧/新施工，两侧36组真实预览，含9笔成功并提交/读档/继续交通、27笔拒绝、9次实际路口拆分。完整预览网络、点、split、价格、grade、revision，以及提交/加载/续跑的城市状态SHA均一致。预览和失败均核对原城市完整状态不变。
- 固定大城市的48个 straight/curve/warmed组合完整RoadPlan签名相同；性能计时外核对原城市不变。
- 全量模型回归通过。普通 SampleScene 原生构建及独立运行通过，包括真实曲线输入、建拆、桥隧、车道、行人、路口、货运、服务车辆和原生存档。这里只运行既有显式无人值守验收，未声称人工完整试玩或UI美术检查。

## 配对性能

纯Mono施工诊断，固定2029节点/1320边城市，两版使用相同逻辑查询及哈希；12轮新鲜城市，排除前2轮，不预热快照的10轮均值：

|预览|旧 ms→新 ms|旧分配 MB→新分配 MB|
|---|---|---|
|直线|0.92→1.09|1.295→1.295|
|曲线|25.01→23.31|29.647→24.224|

曲线均值约降低6.8%，分配约降低18.3%；直线计时有波动、实现不变。不是Unity窗口FPS、原生heap或整步模拟加速。主要剩余成本仍是全图扫描/邻接重建，下一施工优化应先细分它们，再决定局部修改集；不能把草稿称为已完成增量施工。
