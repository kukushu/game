# 生产岗位就业市场 v1：实现与反事实实验

2026-10-30。基线提交 `40981b2`，开发分支 `experiment/labor-market-v1`。只改独立 Python 实验，没有修改 Unity 或合并 main。默认旧配置与旧存档仍用劳动池；新机制必须明确选择。

**结论：已形成可解释、可保存、受道路和工资影响的生产岗位关系，但还不是全城劳动市场。** 小案例中出现了工资竞争、通勤逆转、预算限制、留职与换职。多期城市实验没有保证变好；临时服务仍自动分配，部分短班次无人接受，家庭收入耗尽也受到已暂停分红、资金留存和现有消费/租费制度的强烈影响。建议继续做局部机制验证，暂不替换全城默认规则。

## 1 先核对了哪些依赖

旧链路：`City.step → reset_period → LandCity.enter → PlayCity.production → City.production → operate_stores → consume → settle → check/measure`。

- `commerce/model.py:hire`：固定时薪100，按每期打乱的共享池支付工时。`landlab/model.py:hire` 再扣除实际通勤，保证劳动加通勤不超过8。
- 原生产顺序是工厂0生产、工厂0柜台、工厂1生产、工厂1柜台……；店员与货运更晚。不是企业同时竞争岗位。
- 店员服务受招聘工时限制；货运如果工时不足仍可能付过部分工资但不能完成整批运输。这一旧抽象没有在本轮顺手重构。
- 工资通过 `pay` 真实支付，再按本笔收入代扣税。没有可支付资金就不能透支招人。
- `jobs` 原来按工资分配量加权，在统一工资下等于工时；新生产工资不同时必须按实际工时加权，迁居才能读取有意义的上一期工作地点。
- 工作与通勤共同限8小时；购物仍有单独4小时预算。它们不是现实一天的完整时间日历。
- 工厂选址利润原来写死每件25的生产工资成本；市场模式现按本厂报价/4计算。选址中的劳动力可得性估计仍是粗略平均，不是再运行一遍招聘市场。

旧 `commerce` 与 `playweb` 算法没有改；`LandCity.production` 的 pool 分支仍调用原实现。新增 `batch_pool` 只作离线诊断：所有生产招聘先做完，再安排柜台，仍使用旧固定工资劳动池。

## 2 五个最小案例与结果

相关自动化测试在 `tests/test_labor_market.py`；不以漂亮总量曲线代替这些因果检查。以下内部金额单位100对应网页1K，沿用 cents 命名，但不是现实人民币的“分”。

| 场景 | 人工条件 | 观察到的实际结果 | 能说明什么 |
| --- | --- | --- | --- |
| A 工资竞争 | 仅2户有剩余时间，两厂同等距离，各发布2个4小时班次，报价每4小时4K与6K | 高薪厂雇到2户、生产32件，低薪厂0产量，空缺8小时；高薪厂实际支付12K | 存在稀缺工时下的工资竞争；不是按企业数组先后派人 |
| B 通勤竞争 | 近厂每4小时4K，远厂每4小时5K；两个家庭分别住两端，远厂还有空班 | 一户先选近厂，另一户选远厂；将到远厂路段改良后，前者才换到远厂 | 原远厂往返1.80小时变0.99小时，净收益评分180变261，足以超过原岗位224与稳定门槛22.4；实际通勤却从原近厂0.36升为0.99小时，不能要求每次修路都降低实际通勤 |
| C 现金不足 | 工厂想生产32件，报价150/小时，可用现金123 | 只能支持3件/0.75小时班次，实付113，余款10；实际产量3件 | 需求不直接变成免费劳动或产量；无资金支持的计划与已发布空缺分开记录 |
| D 稳定与换职 | 唯一可用家庭已就业，原价100，另一厂报价先升到105，再升到200 | 小幅变化继续留职；大幅改善后换厂 | 稳定门槛是家庭偏好，企业也优先录用原员工；不是每月随机更换雇主 |
| E 真实反馈 | A场景征30%收入税 | 两户工资合计1200，实际税360，税后到账840；生产仍只由实际8小时产生32件 | 政府和家庭收入来自同一笔真实支付，工厂账户同步扣款。购物预算/消费的后续反馈另在完整城市对照中观察，未给购买量加成 |

还覆盖了低薪完全拒绝、道路不通、工时耗尽、零现金不发布岗位。没有强制让所有家庭就业。

## 3 属性、决策与结算

| 主体 | 最小状态 | 决策与约束 | 实际变化 |
| --- | --- | --- | --- |
| 工厂 | 原库存、销量预期、商品报价、现金；新增按工厂ID保存的工资报价 | 原生产计划仍为 `min(160,max(0,ceil(1.15×预期−损耗后库存)))`；每件需要0.25小时；按现款发布有限班次 | 只有录用并付款后才能生产；招聘报告区分计划、资金支持、空缺、实付与少产 |
| 家庭 | 住址、现金、时间估值、上期生产雇主；现有工作与通勤记录 | 查看四厂公开岗位，比较税后工资与时间；至多接受一个主生产班次 | 实际工资与代扣税入账、增加工作工时、按真实道路往返；保存当前雇主 |
| 临时服务 | 旧共享劳动池 | 柜台、店员、货运用旧固定报价，从生产之后的剩余时间招工 | 仍可能给同一家庭多个临时雇主；不重复使用已消耗的工时或同工作地点已付的往返 |
| 玩家 | 原有财政、道路与土地许可 | 改变通勤、企业/家庭位置、税后收益条件；没有直接指定录用人数 | 企业与家庭在下一次结算重新决策，不保证干预成功 |

**班次**：最多4小时；计划或现金只够较短时间时，末班可缩短到0.25小时的整数倍。家庭不自动拼接第二份生产工作；余下时间仍可供临时服务使用。一个家庭是一个最多8小时的劳动与通勤供给单元，未建家庭人数或现实劳动人口。

**报价**：`factory_wages[str(id)]` 是企业公开时薪（整数账本单位）。本版报价在初始化或实验冲击中指定，企业不会自行加薪/降薪；不能把多工资实验称为内生工资上涨。默认 market 与旧池一样都是100；独立报价冲击另设组，不混进机制主对照。

**收入与评分**（s为班次小时、w为时薪、t为家庭时间估值、c为往返小时）：

```text
班次工资 = 对 s×w 按最近整数结算（半分进位；用整数四分之一小时实现）
本笔税款 = floor(班次工资 × 税率 / 100)
U = 班次工资 − 本笔税款 − t×(0.35×s + c)
可申请：道路可达，现有工作＋已有通勤＋s＋新增往返 ≤ 8，U > 0
若原雇主仍有可接受班次：
    其他雇主的比较分 = U − max(20, 0.10×原雇主最好可行班次的U)
否则不加换职门槛。原雇主与外部岗位同分时优先原雇主。
```

0.35是劳动时间相对通勤的非现金机会成本权重，20/10%是稳定偏好，4小时是班次技术抽象；它们都不是观测所得的真实劳动参数。它们可改变拒绝与空缺，未来应继续做敏感性检验。时间估值不会扣现金，也不制造额外收入。

**匹配**：全部工厂先报班次；家庭按比较分排序申请。每个班次暂留一户，企业优先原员工，其他人用固定种子的中立优先级决定；被拒绝者申请下一班次。直到没有新的申请后，才执行最终工资与生产。每户最多持有一个录用结果，每个班次最多一户。并不是简单按最高工资或工厂遍历顺序先派工。公开岗位板覆盖现有四厂，未模拟搜索成本、信息不对称或真实人事筛选。

种子优先级是必要但外生的配给规则，没有技能差异能解释某户“更优秀”；固定优先级也可能形成持续的收入不平等。工厂/岗位的优先级不通过宏观指标反馈改写。

**阶段**：本期维护与迁居/投资 → 同步生产计划与公开招聘 → 全部生产 → 临时柜台 → 店员与货运 → 购物 → 利润/预期/退出。market 和 batch_pool 让制造先于所有柜台，是明确的结构改变；不能把全部差异都归给自主择业。

## 7 最明显的剩余问题与下一步判断

1. **临时服务仍非自主择业**。家庭拒绝一个不划算的生产班次，随后仍可能被劳动池安排不划算的柜台/运输工作。这是本轮明确保留的边界，不应称全城已自下而上就业。优先将一个最重要服务类型接入同样的报价/申请过程，再扩大范围。
2. **4小时班次与短尾班可能制造缺工**。需要在同初态下单独比较2/4小时、固定班次与可协商时长，检查少产是否主要来自格式，而非低薪或路远。本轮不为填满尾班强制接受，也不把尾班工资直接塞给别人。
3. **持续雇主不等于长期合同**。岗位每期重报，需求缩减会中断关系；40多次退出/重返比表面上的2—5次直接跳槽更值得关注。下一步先核对这些终止原因，不先增加劳动法或技能体系。
4. **企业只会报价，不会内生调整工资**。之后可试一个由本厂空缺、预算及商品毛利触发的小幅调整规则，必须与固定报价组对照，允许工资不涨/企业招不到人。
5. **厂址预期仍粗略**。工资成本已用实际本厂报价，但劳动力供给仍以总可用时间除企业数估计，不知道其他雇主会争走谁；可能夸大新址可用工时。以后用当前岗位板进行有限试算，再比较预测误差；不能拿当前选址利润当保证。
6. **资金循环问题独立存在**。暂停分红又没有真实服务账户支出主体，会把钱长期留存。不要通过就业参数或补工资掩盖；应另开明确的支出/产权对照，保持本实验基线可复现。
7. **规则仍有外生配给与信息假设**。固定四厂、每件0.25小时、全板可见、种子优先级、制造先于所有临时服务、工作/购物两个预算、消费品需求固定，都限制现实解释。部分劳动剩余或收入集中来自这些假设，不能称现实失业率或完整工资市场。

建议保留本分支作为可玩验证版，优先研究“短尾班与职业关系中断”和“临时服务自主接受”，再考虑工资适应；当前不建议合并替换全部城市劳动系统。值得保留的是：工资/道路/预算能通过家庭和企业各自的比较改变真实合同、支付与产量，且失败也能被解释。
