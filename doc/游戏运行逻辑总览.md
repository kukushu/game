核对日期：2026-10-28。实现基线：`69b6e08`。对应当前 `landlab` 网页玩法，默认采用自主选址、稳定迁居规则、工厂直销与零售并存；已包含收入税和地图图层。旧版 `econlab` 和独立商业实验不是本文的默认规则。

**本文描述当前实际实现，不把规划中的功能写成已经存在。尤其是：居民还不会自主比较工作机会，工厂不会新建或破产退出，没有土地买卖市场。**

## 1. 先理解这是一套怎样的模拟

最主要的经济循环是：

> 企业支付工资 → 家庭获得收入 → 家庭购买商品 → 工厂和商店获得销售收入 → 企业继续雇工、生产和补货。

空间条件会进入这个循环：

> 道路与住址 → 通勤、购物和运输时间 → 能否招到劳动、能否完成购买、经营成本 → 企业经营结果与主体选址。

财政在其中形成另一个循环：

> 家庭实际取得工资和分红 → 代扣收入税 → 公共现款 → 道路养护和玩家施工 → 改变经济活动的条件。

系统不直接指定“这个商业区繁荣”“经济增长5%”或“修路后通勤下降20%”。但是需求数量、工资、租金函数、搬迁门槛等微观规则中的很多常数，目前仍由设计者直接设定。

### 单位与符号

| 符号或单位 | 本文含义 |
| --- | --- |
| 金额 | 除明确写“块”外，公式使用分；100分＝游戏里1块 |
| 一期 | 界面上的一个月，是抽象模拟期 |
| 小时 | 模型时间单位；不是把现实月工时压缩后进行人口统计 |
| `h`、`f`、`s`、`n`、`g` | 家庭、工厂、商店、街区、商品 |
| `C`、`I`、`p` | 现金、库存数量、商品单价 |
| `v_h` | 家庭对一小时出行时间的估值，单位分/小时 |
| `d(a,b)` | 沿当前道路网络的最短单程时间；货运时使用货车时间 |
| `MD(a,b)` | 地图曼哈顿距离，即横向格数加纵向格数 |
| `floor`、`ceil`、`round` | 向下取整、向上取整、代码中的四舍五入函数 |
| `clip(x)` | `max(0, min(1, x))`，把数值限制在0到1之间 |

系统给家庭的工作与通勤额度为每期8小时，另有4小时购物上限。这两个预算目前分开计算，不是一张完整的个人时间表。

## 2. 实体与属性总表

### 2.1 谁是主体，谁只是账户或空间条件

| 对象 | 当前规模 | 扮演什么角色 | 实际有哪些决策 |
| --- | --- | --- | --- |
| 家庭 `Resident` | 固定64户 | 消费者、一个劳动力单位、共同资产持有人 | 购物、搬家；没有独立择业策略 |
| 工厂 `Producer` | 固定4家，食品与日用品各2家 | 生产、批发、直销、雇工 | 产量、直销柜台用工、厂址搬迁 |
| 商店 `Store` | 动态进入退出，同时营业最多18家 | 采购、运输、库存、销售、雇工 | 进货、供应商、价格、继续营业或退出 |
| 投资资金池 `fund` | 一个账户和统一投资算法 | 为新店提供启动资金，接收部分回款 | 比较开店方案并选一个投资 |
| 市政 `civic` / 玩家 | 一个账户和一组玩家操作 | 征税、养护、修路和用途规划 | 税率、道路建设和改良、用途许可由玩家决定 |
| 土地服务账户 `property` | 一个结算账户 | 接收租费和部分经营付款，再分红 | 没有自主选址、竞价或经营策略 |
| 街区 | 35块，7×5，每块容量8 | 限定主体能在哪里居住和经营 | 不决策，自身没有目标函数 |
| 道路 | 相邻街区之间的连接 | 承载出行，产生养护负担 | 不决策，由玩家建设 |
| 商品 | 食品、日用品 | 库存、交易与消费的计量对象 | 没有逐件商品代理 |

**没有另一个“个人”层级。** 一户家庭只有一份劳动额度，不包含父母、孩子、年龄或家庭成员数。家庭可能在同一期为不同企业工作。

住宅也不是独立的经济主体。地图每个住宅图标表示最多4户实际住户；它没有独立房价、空置率、房东、按揭或建设企业。

### 2.2 家庭保存哪些属性

| 属性 | 代码位置/字段 | 用途或默认值 |
| --- | --- | --- |
| 身份与住址 | `id`、`node` | 确定所在街区和可追踪身份 |
| 现金 | `accounts['h编号']` | 初始化每户4000分，即40块；不是直接存放在 `Resident` 对象内 |
| 时间价值 | `value_time` | 初始化后固定，约65–135分/小时；影响购物和搬家，不是工资 |
| 环境偏好 | `preferences[家庭id]` | 初始化后固定，约100–350；影响居住评分 |
| 本期劳动 | `work` | 工作为企业提供的实际工时 |
| 本期通勤 | `commute[家庭id]` | 实际发生的往返通勤时间 |
| 本期购物时间 | `shopping` | 实际执行购物方案花费的时间 |
| 本期消费 | `food`、`goods` | 实际买到并用于本期消费的数量，每种最多2件 |

每期重置工作、通勤、购物和消费记录；现金与住址跨期保留。家庭不储存食品和日用品，没有储蓄目标或投资组合决策。

## 3. 每个月按什么顺序运行

玩家点推进时间以后，Python按固定顺序结算：

| 顺序 | 本阶段发生什么 | 影响后续哪一步 |
| --- | --- | --- |
| 1 | 重置本期工作、消费、交通与交易记录，生成可复现的劳动力顺序 | 本期招工和购买从新的记录开始 |
| 2 | 用已有公共现款支付道路养护 | 决定本期道路时间 |
| 3 | 家庭缴住房租金 | 减少搬家和购物前的现金 |
| 4 | 抽取部分家庭考察搬迁，使用上期工作记录和已知经营状态 | 改变本期住址、附近需求和租金条件 |
| 5 | 轮查一家工厂是否搬迁 | 改变后续实际工作、供货地点 |
| 6 | 工厂缴厂房租赁费用 | 减少本期可用生产资金 |
| 7 | 投资池考察新商店 | 有合适方案时新增一个经营主体 |
| 8 | 工厂处理库存损耗、更新需求预期、雇工生产、雇直销柜台人员 | 形成可供批发和直销的库存 |
| 9 | 商店按可复现随机顺序开门、雇工、调价、采购和运输 | 形成居民实际可以买到的货架与服务 |
| 10 | 家庭按可复现随机顺序选购物方案并付款 | 形成真实消费、销售和出行 |
| 11 | 商店算利润、更新销量预期、判断退出；企业和账户分红 | 改变后续经营现金与家庭财富 |
| 12 | 检查现金与商品守恒，记录统计，将本期流量留给下一期 | 下一期继续运行 |

**收入税在工资和分红实际支付时即时代扣，不是在上述流程外凭空计算一笔财政收入。**

先后顺序不是无关紧要的：本期已经买走的货，后面的家庭就买不到；前面的企业用了劳动时间，后面的企业可能招不到；家庭搬家在本期工厂搬迁之前，所以它不能预知之后所有变化。

## 4. 工作怎么分配：现在没有自主择业

### 4.1 当前实际实现

当前还没有“居民浏览工作机会，比较工资与通勤，然后选择最喜欢的雇主”的算法。

现在是**企业发起招聘，系统在共享劳动力池里顺序匹配**：

1. 每期开头随机排列64户家庭。给定相同种子、时期和操作，可以复现同一顺序。
2. 工厂、柜台、店铺、运输依结算顺序提出用工需求。
3. 系统从共享游标所在家庭开始，检查它还有多少工作与通勤时间。
4. 有可用时间且企业付得起，就分配劳动并付工资；不够则继续找下一户。
5. 本期已经到过同一个工作街区，不再次计算该街区的往返。不同工作街区分别计算往返，不是完整的跨工作地连程。

所有行业当前税前时薪都是：

```text
时薪 = 100分/小时 = 1块/小时
```

### 4.2 分配公式

设企业需要工时 `H_need`，企业现金为 `C_f`，家庭已经工作 `H_work`、已通勤 `H_commute`。

```text
企业本次最多可付工资 W_need = min(round(H_need × 100), C_f)

本次新增往返 T_new = 0                         如果本期到过同一工作街区
                     2 × d(住址, 工作街区)     否则

家庭可用工资对应额度 W_available
  = max(0, floor((8 - H_work - H_commute - T_new) × 100))

本次实际税前工资 W_actual = min(企业剩余招聘额度, W_available)
本次实际工作时间 = W_actual / 100
```

只有实际分配了劳动，才记录相应通勤和工资。企业不能花超出现金的钱雇工。

**例子：** 某家庭本期尚未工作，到工厂往返2小时，可供工作最多6小时。企业只需要4小时且有现金，就支付400分税前工资，家庭工作4小时、通勤2小时。税率1%时代扣4分，实际增加现金396分。它还保留2小时的工作与通勤余额，可能继续为其他企业工作。

### 4.3 这个简化意味着什么

| 已经产生的机制 | 尚未实现的机制 |
| --- | --- |
| 通勤越长，可供企业购买的劳动越少 | 家庭根据税后工资、职业偏好挑工作 |
| 工厂、商店和运输争用同一劳动额度 | 企业互相抬工资争工人 |
| 企业缺现金会雇不到足够劳动 | 技能、学历、职业匹配 |
| 不同企业在流程中的顺序会影响劳动分配 | 稳定合同、主动辞职、失业搜寻 |

所以地图上的“工资收入”差异主要来自实际工作量，不是不同街区时薪不同。时间价值 `value_time` 也不是要求的工资或工资报价。

## 5. 家庭怎么买东西

### 5.1 固定目标与候选卖家

每户每期目标为2件食品、2件日用品。消费目标不会因家庭成员、健康或上期饥饿而增加。

先排除没货或没有足够柜台服务的卖家。每种商品按下面的启发式成本排序，只取前三个卖家，并增加一个“不买”选项：

```text
候选排序分数
  = 2 × 单价 + v_h × (2 × d(家, 卖家) + 0.06) / 卖家商品种类数
```

这里考虑卖多种商品可以分担出行成本，但还不是最终购买判断。

### 5.2 组合与实际购买

系统组合食品卖家、日用品卖家和不买选项，检查：

| 检查项 | 规则 |
| --- | --- |
| 路线 | 一家：家→卖家→家；两家：家→A→B→家 |
| 时间 | 每个卖家停留0.06小时；总购物时间不超过4小时 |
| 现金 | 不借钱；先按食品，再按日用品分配现金 |
| 数量 | 每种 `q = min(2, 当前库存, floor(剩余现金/价格))` |
| 柜台服务 | 每个实际访问的卖家需 `0.06 + 0.02 × 购买件数` 小时服务 |

最终比较的效用是：

```text
U = q_食品 × (650 - 食品单价)
  + q_日用品 × (500 - 日用品单价)
  - v_h × 整条购物路线时间
```

选择效用最高的可行方案，且 `U > 0` 才执行。650和500是设定的商品消费价值，不是居民实际收到的钱。

**例子：** 为便于说明，只比较买两件食品，其他条件相同。家庭时间价值为100分/小时：

| 方案 | 单价 | 含停留的总购物时间 | 效用 |
| --- | ---: | ---: | ---: |
| 去工厂 | 100分 | 2小时 | `2×(650-100)-100×2 = 900` |
| 去商店 | 135分 | 0.4小时 | `2×(650-135)-100×0.4 = 990` |

商店更贵，但节约的时间更有价值，所以这个家庭会选商店。如果店里没货、现金不足或柜台没有服务，这个方案不能执行。

这不是全城最优路线求解。家庭只看少量候选；同一组合的购买数量也是按上述规则确定，不穷举所有数量分配。不同家庭先后购买会改变后面家庭能看到的库存。

## 6. 家庭搬不搬家：完整评分与门槛

### 6.1 什么时候考察

默认自主选址模式下，开城前6期不考察迁居；第7期开始，每期随机抽约六分之一家庭，64户时为10户。搬家后至少等待4期，才再次进入可搬迁判断。

候选地必须有住宅许可、道路可达且容量足够。已有住处即使后来改为其他许可，也可以保留，不会被自动驱逐。

### 6.2 住在哪里更划算

每个候选地的综合成本：

```text
S_h(n) = R(n) + G_h(n) + J_h(n) + E_h(n)
```

| 项目 | 公式 | 解释 |
| --- | --- | --- |
| 房租 `R` | `55 + 3×该地家庭数 + 5×该地已用土地` | 当前报价，不是竞价成交价 |
| 购物预期 `G` | 对两种商品分别取 `min卖家[2×单价 + v_h×(2d(n,卖家)+0.06)]`，再相加 | 每种商品估计买两件；没有完整重演实际购物组合和缺货 |
| 通勤预期 `J` | `v_h × Σ雇主[2d(n,雇主位置)×上期该雇主工资] / max(1,上期总工资)` | 使用上期工作地点，按税前工资加权；上期没有工资时，该项为0 |
| 干扰指数 `P` | `Σ工厂[(最近实际产量/100)/(1+MD(n,工厂))²]` | 在本期生产前考察，所以通常读到的是上期产量 |
| 环境成本 `E` | `environment_weight × 家庭环境偏好 × P(n)` | 默认环境权重1；不是实际现金支出 |

选择 `S` 最低的候选地。分数相同时，代码优先编号较小的地点。

这里的购物预期和真正购物算法是两套不同精度的计算：迁居时用廉价近似，实际买东西时检查货、钱、柜台和路线。因此预期改善不保证以后每期实现。

### 6.3 值得搬吗

设原住处成本 `S_old`，最好候选成本 `S_best`：

```text
预期改善 gain = S_old - S_best
最低改善 required = max(120/6 + 30, 0.10×S_old)
                  = max(50, 0.10×S_old)

搬迁需要同时满足：
  候选地不是原住处
  gain > required
  家庭现金至少120分
  已经过搬家冷却，且候选地合法、有容量、可达
```

成交后家庭付120分给土地服务账户，变更住址并记录时间。每期50分的基础门槛来自搬迁费按6期摊销再加30分安居门槛；10%是额外的相对改善要求，并不是实际再扣一笔钱。

**例子：** 原住处综合成本1000分、候选地920分。改善80分，但门槛是100分，所以留下。候选地若为800分，改善200分，就通过收益门槛；仍要检查现金、冷却和土地等条件。

这些成本是“现金费用＋时间与环境估值”的组合。不能把它们全部看成家庭账本的实际支出。

### 6.4 为什么仍可能反复搬

预期使用上期岗位和当时交通、价格、住户数量。它没有稳定工作合同，也没有多期持续收益确认。提高门槛减少了小波动搬迁，但没有消除所有短视和预测误差。

研究用 `legacy` 迁居规则只要求改善超过50分；默认 `stable` 使用上述10%门槛。固定位置模式不搬迁，随机选址模式不比较收益，但仍受现金、冷却和合法地块约束。

## 7. 工厂怎么生产和搬迁

### 7.1 产量不是直接由全城需求指定

工厂先处理旧库存损耗，再更新自己的需求预期：

```text
E_new = 0.6×E_old + 0.4×(上期实际销量 + 记录的未满足订单)
Q_target = min(160, max(0, ceil(1.15×E_new - 损耗后库存)))
计划生产工时 = 0.25×Q_target
Q_actual = floor(实际雇到的生产工时/0.25)
```

“未满足订单”主要来自商店有资金支持但没有采购成功的补货需求，不等于所有买不到东西的家庭需求。没有收到订单的工厂，预期可能持续下降。

| 决策 | 当前规则 |
| --- | --- |
| 做什么产品 | 初始化固定，每厂只做食品或日用品；不转产 |
| 生产多少 | 上述预期和库存规则；每期目标最多160件 |
| 有无能力生产 | 取决于现金、真实劳动与通勤；缺现金不能凭目标生成商品 |
| 直销柜台用工 | 常态 `1 + 0.05×max(12,1.2×上期直销量)` 小时；第一期按库存安排 |
| 出厂价 | 默认食品100分、日用品140分，不自主调整 |
| 没现金怎么办 | 可能停产和失去柜台服务；没有正式破产退出或新工厂进入机制 |

代码保留了研究性工厂调价开关：若开启，未满足订单大于3时尝试涨1%；否则库存大于销量时尝试降1%，下限40分。网页默认关闭，不应把它当当前默认玩法。

### 7.2 如何评价一个厂址

工厂只考虑现址以及有工业许可、可达、至少空余4单位土地的地点。

```text
V(n) = min(160, 预测直销D(n) + 预测批发B(n), 可用劳动L(n)/0.25)
厂址费用 = 企业租金(n,面积4) + 100
预测利润 Π(n)
  = V(n)×(出厂价 - 25)
  - 100×[1 + 0.05×min(D(n),V(n))]
  - 厂址费用
```

25分是一件商品所需0.25小时生产劳动的工资成本。柜台用工与厂址费用也进入预期，尚未完整模拟未来真实招工。

| 预测项 | 当前估算 |
| --- | --- |
| 直销综合报价 | 工厂：`单价 + v_h×(2d+0.06)/2`；商店竞争报价按其商品种类数分摊购物时间 |
| 家庭直销份额 | 往返不超过4小时时，`2×clip[0.5+(竞争者最低综合报价-自己报价)/100]`，对家庭相加 |
| 批发需求 | 对相关营业商店相加：`该商品预期采购量×clip(0.5+其他工厂最短货运时间-自己货运时间)` |
| 可用劳动 | `Σ家庭 max(0,8-2d(家庭住址,n)) / 当前工厂数` |

### 7.3 搬厂条件

前6期不考察；之后每期轮查一家工厂。搬迁需要：

```text
最佳候选地预测利润 - 现址预测利润 > 1200/6 + 200 = 400分/期
工厂现金 >= 1200分
上次搬厂后至少8期
候选地合法、有容量、可达
```

满足后实际支付1200分，即12块。这里的预测利润是搬迁比较用的近似值，不是已赚到的利润，更不是系统承诺的未来收入。

## 8. 商店怎么开业、采购、定价和退出

### 8.1 先区分开店者与已开业店铺

新店由统一投资资金池比较方案并出资；不是每间既有商店自己扩张分店。默认有两类方案：

| 面积 `A` | 土地占用 | 库存容量 `K` | 计划店员工时 `H` | 默认商品 |
| --- | ---: | ---: | ---: | --- |
| 小店1 | 1 | 48 | 5小时/期 | 食品或日用品中的一种 |
| 大店4 | 4 | 192 | 14小时/期 | 两种商品 |

公式为 `K=48A`、`H=2+3A`。大店的库存按经营商品种类分配空间；两种商品时各最多96件。当前没有购物中心、连锁品牌、商店扩建或商品种类自主调整。

### 8.2 是否开店、开在哪里

每期最多抽8个没有营业商店的街区考察，再检查商业许可、剩余土地和连通条件。有足够资金且预测盈利的方案才进入比较，每期最多新增一家，同时营业上限18家。

设 `R(n,A)` 为企业租金，`H=2+3A`，`K=48A`：

```text
预期开门和用工成本 O = R(n,A) + 100H + 100
试算初始售价 p0_g = round(最低出厂价_g + 8 + O/(0.7K) + 10)
```

其中8、10和70%计划销量是当前经验参数，不是市场求解得出的常数。

| 步骤 | 计算规则 |
| --- | --- |
| 看顾客能否到达 | 家到候选店往返加停留不超过4小时 |
| 比较综合报价 | `c_hg = p0_g + v_h×(2d+0.06)/(2×店铺商品种类数)` |
| 预测购买份额 | 有竞争报价时 `share=clip[0.5+(竞争者最低综合报价-c_hg)/100]`；没有竞争报价时为1 |
| 预测需求 | `D_g=Σ家庭 2×share`；若总量超过库存容量，按比例压缩到容量内 |
| 预测运费 | 按该商品路程最近的工厂和预测采购数量计算运输费 |
| 预测利润 | `π=Σ商品[(试算售价-最低出厂价)×预测销量] - O - 预测运费` |
| 周转资金 | `W=round[48A×130 + 2×(R(n,A)+100H)]` |
| 开店手续费 | `F=800+600A` |
| 是否可投资 | `π>0` 且资金池现金至少 `W+F` |
| 投资哪个方案 | 选 `π/(W+F)` 最大者 |

资金池将周转金转给新店，将手续费转给土地服务账户，创建真实商店对象。商业许可本身不会触发建筑出现。

**预测会犯错。** 它参考竞争者标价，不完整检查其未来库存、停产、缺货或连程购物，也不完整模拟未来工人和现金竞争。因此城市有缺货，不等于某块商业地一定被预测为值得投资。

### 8.3 已开业商店如何运作

先检查现金能否覆盖租金、固定开门费与计划店员工资：

```text
最低开门资金 = R + 100 + 100H
```

现金不足时本期不开柜台，连续两期不足退出。现金够时支付租费、实际雇店员、处理库存损耗、调价和采购。实际招到的劳动可能少于计划。

| 决策 | 公式 |
| --- | --- |
| 下一期销量预期 | `E_new,g = 0.65E_old,g + 0.35×本期该商品实际销量` |
| 目标售价 | `p_target,g = round[库存平均单位成本_g + (R+100+100H)/max(4,预期总销量) + 10]` |
| 本期售价 | `p_new,g = max(10,round(0.8p_old,g+0.2p_target,g))` |
| 目标库存 | `I_target,g=ceil(1.1E_g)` |
| 采购需求 | `need=max(0,min(容量/商品种类数取整-现有库存,I_target,g-现有库存))` |
| 供应商排序 | `出厂价 + 本次运费/max(1,采购数量)` 越低越优先 |
| 可采购数量 | 不超过供应商库存；出厂付款加运费必须付得起；还必须雇到运输劳动 |
| 新库存单位成本 | `(旧库存×旧单位成本+本次出厂付款+本次运费)/(旧库存+到货数量)` |

采购不是预约未来产量。工厂先完成当期生产，商店再从当时已有库存中买货。商店顺序不同，会改变后面商店可买到的数量。

如果运输劳动不足，本次货不移动；尝试雇用过程中已支付的部分工资仍可能成为成本。

### 8.4 运输怎么算

采购量为 `q`，货车最短单程时间为 `d_truck`：

```text
车次 trips = ceil(q/32)
运输工时 = 2×d_truck×trips + 0.15×trips + 0.012×q
运费 = round(运输工时×100) + 60×trips
```

工时对应真实付给家庭的货运工资，车辆费用进入土地服务账户。商店再贵也不能只扣一个抽象运费就获得不存在的库存。

### 8.5 实际利润和关店

```text
本期实际利润
  = 期末现金 - 开门前现金
  + 期末库存成本价值 - 期初库存成本价值
```

| 退出原因 | 条件 | 后果 |
| --- | --- | --- |
| 缺现金 | 连续两期无法覆盖最低开门资金 | 停止营业，释放土地 |
| 连续亏损 | 店龄至少6期，且连续4期利润为负 | 同上 |

退出时库存核销为损失，剩余现金转回投资池。商店对象和历史仍保留，但 `active=false`，地图不再把它画成营业商店。

食品库存每期约损耗12%，日用品约1.5%，通过整数损耗加随机小数抽样实现。库存归工厂或商店所有；家庭不囤货。

## 9. 道路、土地、租金和生产干扰

### 9.1 道路时间

每段道路的时间：

```text
单段时间 = 基础时间 × 道路系数 × (2-养护比例)
         × (1+0.12×上期该路流量/12)

居民基础时间 = 0.18小时/段
货车基础时间 = 0.045小时/段
普通道路系数 = 1
改良道路系数 = 0.55
```

沿道路寻找总时间最短路径，不是直接用几何距离。不能到达的地点不允许主体正常进入。

拥堵用上期流量，不模拟本期实时排队，也不区分真实车道数。通勤、购物和货运都会记录道路使用。

### 9.2 土地用途与容量

| 用途 | 允许新增主体 |
| --- | --- |
| 保留空地 | 无 |
| 住宅 | 家庭 |
| 商业 | 商店 |
| 工业 | 工厂 |
| 住商混合 | 家庭、商店 |
| 自由混合 | 家庭、商店、工厂 |

```text
已用土地 = ceil(家庭数/4) + 营业商店面积之和 + 4×工厂数
空余土地 = 8 - 已用土地
```

用途是进入许可，不是立即建成。已有主体改许可后不会自动消失或被强制迁走；合法的新进入仍要考虑容量、连通和自身收益。

### 9.3 当前有租金，没有土地售价

```text
住宅每户租金报价 = 55 + 3×当地家庭数 + 5×当地已用土地
企业租金(n,A) = round[(160+1.8×附近家庭数)×A]
附近家庭：曼哈顿距离不超过1的街区中的家庭
工厂实际厂址账单 = 面积4的企业租金 + 100
商店开门租费账单 = 企业租金 + 100
```

这些是设定的收费函数，没有地块产权竞价、土地售价或开发商。家庭和工厂现金不够时只支付可付金额，没有形成欠租债务或强制退出规则。商店另有明确的开门资金检查。

家庭在本期搬家前缴旧住址租金；工厂搬迁后再缴当期厂址费用。代码目前没有重算家庭当期新旧住址的租金差。

### 9.4 生产干扰

生产干扰只由最近产量和曼哈顿距离计算，见第6节。它进入家庭选址评分，但不会直接扣现金、伤害健康或降低劳动生产率。道路和商店也没有一套完整的噪音、健康外部性模型。

## 10. 税收、账户与资金循环

### 10.1 税收

玩家可设整数税率0–30%，新旧存档默认0%。调税本身免费，不立即扣存款。

```text
每笔收入税 = floor(本笔实际工资或分红 × 税率 / 100)
家庭到账净增加 = 本笔收入 - 本笔税
公共账户增加 = 本笔税
```

税基包括生产工资、直销柜台工资、店员工资、货运工资、家庭权益分配和基金分红。不对存款、商品买卖、企业投资直接再征这项税。逐笔取整会使小额分笔收入的有效税率略低于名义税率。

企业支付的税前工资不变；家庭税后现金改变后，实际购物能力可能改变。没有把高税直接写成“企业离开”或“产量下降”的宏观公式。

### 10.2 公共预算和养护

```text
每期养护需要 = 4 × 全部道路等级之和       （默认无额外实验养护项）
实际支付 = min(现有公共现金, 养护需要)
养护比例 = 实际支付 / max(1,养护需要)
```

普通路每段每期0.04块，改良路0.08块。公共财政没有借债功能；不足时减少实际养护，进而增加道路时间。

建设费是新路12块、改良9块、改一块用途2.50块。支付后改变地图条件，没有模拟道路施工企业、施工工人、建材生产或施工等待期。

养护在月初支付、税在收入发生时收取，所以从零预算开始开税，第一期仍可能付不起养护，第二期才恢复。公共现金储备本身不是居民财富增加，也不代表消费改善。

### 10.3 钱流向哪里

| 付款 | 谁付给谁 | 规则 |
| --- | --- | --- |
| 工资 | 企业/商店 → 家庭 | 实际雇到的工时×固定时薪，再由家庭代扣税 |
| 消费 | 家庭 → 商店或工厂 | 实际成交数量×售价 |
| 批发 | 商店 → 工厂 | 实际到货数量×出厂价 |
| 租费与部分服务费 | 主体 → `property` | 按上述账单和实际可支付金额 |
| 规划、修路、养护 | `civic` → `property` | 真实公共账户支出 |
| 开店 | `fund` → 新商店和 `property` | 周转金给店，手续费给土地服务账户 |
| 收入税 | 家庭 → `civic` | 实际收入的逐笔代扣 |

结算时还有固定的资金分配：

```text
工厂转给property = floor(max(0,工厂现金-8000)/2)

商店经营储备 = round(48A×130 + 企业租金 + 100×计划店员工时)
商店转给fund = floor(max(0,商店现金-经营储备)/2)

property给每户分红 = floor(property可用现金/家庭数)
fund给每户分红 = floor(max(0,fund现金-180000)/家庭数)
```

这是共同持股的简化设定。没有独立地主、股权交易或家庭持股比例差异。基金会优先恢复保留资本，超过初始资本目标才向家庭分红。

### 10.4 守恒约束

```text
所有现金账户合计 = 初始现金总额
期初商品库存 + 实际生产 = 实际消费 + 损耗/核销 + 期末库存
```

税收和施工支出是账户间转移，不创造现金。只设置目标、许可、预期订单或收益评分，都不生成真实商品。

## 11. 从空白开城，与后续自主发展有什么区别

空白阶段没有家庭、工厂、商店或隐形生产活动。玩家有300块规划预算，先修路、划用途，不推进经济时间、不扣月养护。

点击“开放城市”时，系统进行一次初始化：

1. 找一个道路连通片区，确认能容纳64户和4家工厂。
2. 逐个安置工厂：在合法、有容量的工业地点中，优先离允许住宅的地块平均路程较近的位置，并保证留得下全部家庭。
3. 逐户安置家庭：在合法住宅位置中按居住评分选择；开城时还没有上期岗位和实际生产干扰。
4. 把这套布局保存为同状态经济对照起点，再开始逐期生产和交易。

这是既定主体的一次初始化，不是居民每月自主迁入、人口增长或企业创立过程。64户和4家工厂不是市场逐步选择出的规模。

两个住宅地块、两个工业地块以三段路连通，就是一个足够容量的简单例子：三段路36块、四次用途许可10块，规划费合计46块，开城时剩254块。

初始化的原始资金安排为家庭共2560块、工厂共800块、投资池1500块、市政300块，共5160块。规划已付费用从市政转入土地服务账户；没有因开城额外发一轮钱。

## 12. 玩家干预怎样传导到经济结果

| 玩家操作 | 先直接改变什么 | 主体随后可能怎样反应 | 不保证发生什么 |
| --- | --- | --- | --- |
| 修路、改良道路 | 路径、行程时间、未来养护费用 | 劳动可用时间变化、购物方案变化、进货成本变化、客流转移、重新选址 | 不保证所有人通勤下降，也不保证所有店受益 |
| 规划住宅 | 新增合法居住候选位置 | 被考察的家庭比较收益和搬家条件 | 不立即生成人口或住宅开发企业 |
| 规划商业 | 增加合法商店候选位置 | 资金池考察并比较预期利润 | 不保证被本期抽到，不保证开店或盈利 |
| 规划工业 | 增加合法厂址候选位置 | 轮到的工厂考虑是否搬迁 | 不新增第五家工厂 |
| 提高收入税 | 减少家庭后续净收入、增加公共现金 | 购买力变化；未来养护和可施工能力变化 | 不保证综合福利提高，不直接赋值经济增长 |
| 降低收入税 | 给家庭保留更多后续收入 | 消费、储备和经营结果可能变化 | 不退还过去已收税，也不直接给企业补贴 |

例如修一条路之后，附近家庭不一定搬家：它可能只改变购物地点；如果商店因此失去顾客，数期后才亏损退出；工厂再从销量中更新需求，调整下一期产量。这种先后传导是观察玩法的重点。

## 13. 怎样读懂图层、统计和对照

### 13.1 统计是结果，不是直接控制项

| 指标 | 口径 | 常见误解 |
| --- | --- | --- |
| 食品满足率 | `全体食品实际消费/(2×家庭数)` | 75%不是“正好75%的家庭吃饱”，也不是现实营养指标 |
| 日用品满足率 | 同上，换成日用品 | 可能有家庭部分满足，而非单纯买齐/没买齐 |
| 平均通勤 | `实际通勤总时间/家庭数` | 含未通勤者的零值，低通勤也可能伴随低就业 |
| 平均购物时间 | `实际购物时间总和/家庭数` | 没成功执行购物的人可能记零，数值下降不一定更好 |
| 每件耗时 | `(生产、柜台、店员、货运劳动时间+购物时间)/max(1,成交件数)` | 沿用旧商业模型口径，未包含土地版新增的通勤；不是完整社会总耗时 |
| 价格 | `实际消费付款/实际成交件数` | 是成交均价，不是全市所有标价平均 |
| 零售份额 | `零售成交件数/总消费件数` | 是商品件数口径，不是营业额份额 |
| 家庭工资图 | 按当前住址归集本期实际税前工资，再除家庭数 | 不是企业所在地工资支出，不是时薪差异 |
| 税后收入图 | 工资和分红减实际收入税，按住址取每户均值 | 不是存款，也不是扣除房租和消费后的结余 |
| 租金图 | 现有住户或住宅许可地块的当前住宅报价 | 不是土地买卖价格 |
| 购物缺口图 | 每户尚缺的商品件数，目标共4件 | 不能只凭缺口判断是缺货、缺钱还是出行太远 |

无住户的街区没有家庭平均工资或通勤，显示“无数据”；刚开城尚未结算也不伪造工资或缺货记录。颜色越深只表示数值越高，不表示好坏。

### 13.2 同城对照和可复现性

开城或手动设对照时，从同一完整模型状态复制参考城市。之后两城同步推进，但对照不接收新的规划、修路和调税。

所以从开城一直使用的对照，包含的是此后全部干预的累计差异。想单独看一次调税或修路，应该先从当前状态重新设对照，再做这一项干预。不能把多年差异都归因于最后一项操作。

随机种子控制偏好初始化、招工顺序、家庭购买顺序、考察候选、补货顺序和部分损耗。同初态、同种子、同操作可复现；不同操作会改变后续交互，不能要求不同方案中每个主体都保持同一条轨迹。

## 14. 当前简化、未实现内容和实现入口

### 14.1 判断设计时必须记住的限制

| 领域 | 当前边界 |
| --- | --- |
| 家庭 | 固定64户，无个人成员、年龄、生育、死亡或外部迁入迁出 |
| 工作 | 企业顺序匹配劳动；工资统一，无自主择业、技能和长期合同 |
| 居住 | 有用途、容量、给定租金和搬家评分；无住宅开发商、空置房、房价与按揭 |
| 企业 | 工厂固定4家，无新建和正式退出；零售商有进入退出，无扩建和连锁 |
| 商品 | 固定两种，目标需求和基础消费价值给定；没有家庭囤货 |
| 健康 | 没吃够不会导致死亡、健康或生产率变化；污染也无健康反馈 |
| 金融 | 无银行、贷款、利率、债务、企业债权人 |
| 城建 | 修路和改许可即时发生，无施工周期、建筑材料和施工企业 |
| 税收 | 只模拟实际家庭收入代扣，没有避税、劳动供给弹性或税率引发的外部迁出 |
| 预测 | 搬家、工厂选址、开店和真实交易的计算精度不同，不是统一的完全理性均衡求解 |
| 所有权 | 家庭共同持股、固定分红规则；没有财富份额和产权交易市场 |

这些边界是现有原型的实际范围。评估某种现象时，应区分微观互动的结果、直接设定的制度规则以及算法近似造成的假象。
